# Design

## 技能怎么生效：定义登记时机、挂载时由内核订阅

```lua
Skill '奸雄'
    : kind '被动'
    : on('伤害-结束', function (skill, damage) ... end)

player:addSkill('奸雄')   -- 返回 Skill 实例
```

- **订阅写在技能的「被动」钩子里、绑在 `host` 上**（用户 2026-09-30 定，分两步）：`SkillDef:on('被动', function (skill, host) host:bindGC(owner:on(...)) end)` —— 与装备技能（`CardDef:on('被动', function (card, zone, host) host:bindGC(…) end)`）**逐字同款**。
  - 最早实现是「内核自动订阅定义里登记的每个时机」，改成「被动」的理由：① 有些被动效果**要建状态**（计数 / 标记 / buff），自动订阅那套没有「挂载时准备」的位置；② 装备技能与武将技能只学一套；③ `'被动'` 只有一个名字 ⇒ `SkillDef` 那处**按名收窄**整个可以删掉（少一个 meta 坑）。
  - **绑 `host` 而不是绑技能实例**（用户 2026-09-30 追加）：**技能和装备一样可能被禁用**（被克制 / 封印）—— `skill:disablePassive()` 时内核 `Delete(host)`，订阅与资源一起撤；`enablePassive()` 时重跑钩子、重建容器。**层数计数**让「嵌套停用」能对称撤销（照 `Card:enablePassive` / `disablePassive` 实现）。
- **回调签名 `(skill, ...载荷)`**（照 `Buff:fireHandlers` 传 `(self, ...)`）：技能需要知道自己是谁的（`skill.owner`），而载荷形状由时机决定。
- **`kind` 本批不参与驱动**（与用户口径一致：它只影响「按钮能不能点」）。「问不问」由技能自己写（`game:askChoice(...)`，与装备技能十张同款 —— 【奸雄】就是「问一次，不答不发动」）。
- **实例照 `Buff`**：`Skill : GCHost`，`remove()` = `Delete`，`__del` 里 `owner:removeSkill(self)` + 订阅由基类放掉 ✓ 幂等。

## 「造成伤害的牌」为什么显式传，而不是翻 `parent`

`Damage` 只有 `from` / `to` / `amount` —— 【奸雄】要「造成伤害的牌」，只能：
- **(a) 显式给**：`game:damage(from, to, amount, card?)`，调用点传 `cardEffect.card`（`CardEffect` 本来就有 `.card` 字段 ✓ 五处调用点手边就有）。
- (b) 翻 `parent` 链：`damage.parent` 一般是 `CardEffect`（可拿 `.useCard.card`），但判定阶段那次生效的 `CardEffect` **没有 `useCard`**（【闪电】就是这样），翻链要分层兜底、还要把它写进内容侧的约定里。

选 **(a)**：`Damage` 与 `game:damage` 都在**内容侧**（`@基础/伤害.lua`），加一个可选参数**不碰内核**，而且「这次伤害是哪张牌造成的」本来就该由**造成伤害的一方**说了算（将来有牌的技能直接造成伤害时同样适用）。**无牌的伤害**（无来源、纯技能伤害）传空 ⇒ 【奸雄】连问都不问（没东西可拿）。

## `'伤害-结束'` 给承受者再发一份

时机名**带方向词**：全局一份叫 `'伤害-结束'`，承受者那份叫 **`'伤害-目标-结束'`** —— 照既有规则「对当事人再发一份时，玩家对象那份按当事人角色插词（来源侧插 `来源`、承受侧插 `目标`）」，与 `'伤害-开始'` ↔ `'伤害-来源-开始'` 对称。这样【奸雄】写 `owner:on('伤害-目标-结束', ...)` 就行，不用每次自己比 `damage.to == owner`。

（写第一版时我照了「早期三个同名两份」的老口径，评审时按上面这条规则改回带方向词。）

## 获得之后那张牌不会重复进弃牌堆

【杀】的流程是：`'卡牌-结算前'` 把牌放进**处理区** → 伤害（含【奸雄】在这里把牌拿走）→ 结算完内核把**临时区里剩下的牌**批量 `accept` 进弃牌堆。⇒ 牌已被拿走 ⇒ 不在临时区的列表里 ⇒ 不会再被搬一次。**不需要为【奸雄】加特判**。

## 本批不做

- **`setHero` 里自动挂技能**：还差主公技的时序口径（身份在 `'游戏-开始'` 才发、`setHero` 可能更早）⇒ 下一批连同【护驾】一起做。
- **主动技的发动入口**（`kind == '主动'` 怎么被点）、**技能被压制 / 无效**、技能与装备技能的体系合并。
