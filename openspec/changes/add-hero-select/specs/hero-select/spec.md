# Spec Delta

## Purpose

定义**选将**用到的两块对外契约：① 一个「在若干武将里挑」的询问（`askHero`，含它的时机名）—— 客户端要据此渲染候选并回话；② 开局流程里比 `'游戏-开始'` **更早**的一步（`'游戏-准备'`）—— 身份与选将都发生在它里面。

## ADDED Requirements

### Requirement: 武将的分类

系统 SHALL 让内容侧给武将声明**分类**（`HeroDef:kind(名或名单)` / `addKind(名或名单)` / `isKind(名)` / `getKinds()`），语义与牌的 `CardDef` 分类一致：`kind` 一次调用把分类定下来（重复调以后写的为准）、`addKind` 只追加、`getKinds` 给快照（按声明顺序）。内核 MUST NOT 解释分类的取值。系统 MUST NOT 要求武将继承某个公共模板。

#### Scenario: 打上分类

- **WHEN** 一名武将声明 `addKind('君主')`
- **THEN** 它的 `isKind('君主')` 为真、`getKinds()` 里含「君主」

#### Scenario: 再打一个分类

- **WHEN** 已经打过「君主」的武将又 `addKind('测试')`
- **THEN** 两个分类都在、顺序是声明顺序，且重复打同一个名字不会重复出现

### Requirement: 武将询问（`askHero`）

系统 SHALL 提供 `game:askHero(被问者, 缘由, 条件?)`（`AskHero : Effect`，`kind` = `askHero`）：**候选是一份武将名单**（条件 `hero` 给一名或一批；**不给条件 = 不做限制**），询问 SHALL 把候选名单摆到 `ask.options` 上再交给应答方。应答方的答复 SHALL 是一名或一批武将，且 MUST 落在候选名单里、个数 MUST 落在 `min` / `max` 之间（`min` 省略 = 1、`max` 省略 = `min`）、MUST NOT 重复 —— 不合法一律拒收（`.err` 记原因，对调用方与「没答上」同一个分支）。结果 SHALL 读作 `.hero`（第一个）/ `.heroes`（恒列表，没答是空表）。

询问 SHALL 走**它自己的时机** `'武将-询问'`（照技能询问的先例单开一个名 —— 武将既不是牌也不是角色），应答方**返回值就是答复**、返回空 = 不表态、**第一个给出答复的胜出**；一次答复落定之后 SHALL 触发 `'武将-答复'`。

`min` 为 0 时「一个都不选」SHALL 是合法答复（空答复算成立）；没有一个应答方表态时：`min` 为 0 SHALL 算成立（结果为空）、否则 SHALL 记成「取消」、询问不成立。

#### Scenario: 一次往返

- **WHEN** 候选给了三名武将，应答方返回其中一名
- **THEN** 询问成立，`.hero` 是那一张、`.heroes` 只有它

#### Scenario: 答复不在候选里

- **WHEN** 应答方返回一个不在候选名单里的武将
- **THEN** 询问被拒收，`.err` 指出答复不在可选项里

#### Scenario: 一次挑多个

- **WHEN** 条件写 `{ min = 2, max = 2 }`，应答方返回两名候选
- **THEN** 询问成立，`.heroes` 是这两名；若只返回一名，则被拒收（至少要指定 2 个目标）

#### Scenario: 不必选就能确定

- **WHEN** 条件写 `{ min = 0 }`，应答方不表态（或给空表）
- **THEN** 询问成立，`.heroes` 是空表

#### Scenario: 没人表态

- **WHEN** 条件没写 `min`（默认 1）而没有应答方表态
- **THEN** 询问不成立，`.err` 是「取消」

### Requirement: 开局前的准备时机

系统 SHALL 认一个**比 `'游戏-开始'` 更早**的时机名 `'游戏-准备'`（由装配侧 fire，照 `'游戏-开始'` 的先例 —— 内核不代劳）。身份与选将 SHALL 发生在这一步；`'游戏-开始'` 一方的既有职责（体力默认值、主公加成、建牌堆）MUST 保持在它自己那一步。

#### Scenario: 两步的先后

- **WHEN** 装配侧先 fire `'游戏-准备'`、再 fire `'游戏-开始'`
- **THEN** 两个时机的订阅者各按自己的步跑；准备步里定下的武将，在开始步里读得到（体力与主公加成照它算）
