# Design

## 1）官方口径（本批采用的版本）

> 依据：官方牌面文本（biligame wiki 核对 2026-09-28）+ `sanguosha-rules`（§2.7 抵消 / §3 阶段 / §9.8 判定）+ 用户对五个问题的拍板（2026-09-28）。

1. **使用**：按普通锦囊的规矩（`'获取目标'` 给合法目标）。目标通过校验后，这张牌**置入目标的判定区**（闪电的目标是使用者自己）。（**2026-09-28 更正**：使用期**没有**无懈窗口 —— 原写「使用时有无懈窗口」是错的。）
2. **判定阶段**：目标的判定阶段里，**逆序**结算其判定区（后置入的先判）。每张：**判定前问无懈** → 未被抵消则进行判定 → 按结果**由牌自己**处理 → 结算完还留在判定区就进弃牌堆。
3. **乐不思蜀**：判定**不是红桃** ⇒ 该角色**跳过下一个出牌阶段**；是红桃 ⇒ 无事发生。
4. **闪电**：判定为**黑桃 2~9** ⇒ 该角色受 **3 点雷电伤害（无来源）**，牌进弃牌堆；否则**牌自己**从下家起找**第一个合法目标**（存活、判定区里没有闪电）并移动过去。
5. **同名限制**：判定区里不能有同名牌 ⇒ 不能对判定区已有同名者的再次使用（**在 `'获取目标'` 里判断**）；闪电的传递走同一口径（找合法目标）。
6. **跳过阶段 = 该阶段不发生**（**不进阶段**，`'阶段-开始'` / `'阶段-结束'` 都不发）。官方口径：阶段被跳过就视同没有这个阶段（先例：兵粮寸断跳过摸牌阶段 ⇒ 「摸牌阶段开始时」不触发）。
7. **逐张**：判定区每张牌是**独立的一次结算** ⇒ 各自一个无懈窗口（第一张被抵消不影响第二张）。
8. **阵亡**：官方口径「判定区的牌进弃牌堆」**本批不做**（归以后的「死亡规则」批次）；**回合内死亡 ⇒ 这个回合不再进行后续阶段**（`runTurn` 每阶段前判存活，死了 `break`）。

## 2）使用期：模板 `延时锦囊牌`（与 `锦囊牌` 同在 `package/@基础/卡牌/锦囊牌.lua`）

```lua
Card '延时锦囊牌'
    : extends '锦囊牌'
    : kind { '锦囊', '延时锦囊' }   -- 覆盖掉「非延时锦囊」（extends 的抄写规则见 sanguosha-rules §9.3）
    : on('获取目标', function (plan) ... end)   -- 通用过滤：判定区已有同名牌的目标去掉
    : on('生效', function (cardEffect) ... end) -- 把牌置入 cardEffect.target 的判定区
```

- **同名过滤写在模板的 `'获取目标'` 里**：多条 `'获取目标'` 取**交集**（`collectLegalTargets`），模板的过滤与各牌自己的目标（乐不思蜀：其他角色；闪电：自己）自然叠加 —— 具体牌只写自己那条（1 号问题的落点）。
- **置入放 `'生效'`**：一目标一次、且**被无懈抵消就不跑** ⇒ 「被抵消 ⇒ 不置入判定区、牌照常进弃牌堆」天然成立（官方「抵消 = 此牌对该目标不生效」）。放 `'结算前'` / `'结算后'` 都不行 —— 那两处被抵消也照跑。
- 两张牌都是单目标（乐不思蜀一名其他角色、闪电自己），不存在「一张牌置入多个判定区」的情况。

## 3）结算期：`package/@基础/延时锦囊.lua`

- **一个结算 = 一个效果**：`Class('延时锦囊结算', 'Effect')`（`kind = '延时锦囊结算'`；字段 `player`（判定者）/ `card`（被结算的牌）/ `judge`（这次的判定，被无懈抵消时没有））。
  - `settle()`：`self.judge = game:judge(player, card.name)` → 跑牌自己的钩子（下一条）→ 完事。**清牌不在这里**：收尾统一由驱动做，这样「被抵消（settle 没跑）」与「跑完了」两条路只管一处。
- **牌的结算逻辑 = 新 CardDef 钩子 `'判定结果'`**（载荷 = 结算效果自己）：`card:getDef():getHandlers('判定结果')` 由**内容侧驱动自己跑**（`CardDef:on` 的事件名本来就是自由字符串；类型注解补进 `@基础/meta.lua`，不动内核类型文件）。
  - 不复用 `'生效'`：它已经是使用期「一目标一次」的钩子（模板的置入用它），再叠上「被判定」会让牌分不清两个时刻。给结算另开局级时机的备选也否了（牌的行为写在牌定义上；不然无懈那半要手写）。
- **驱动**（落 `阶段/判定阶段.lua` 的本地函数；它自己订阅 `'阶段-开始'` 接上）—— 判定区是**有序区**（进入顺序先进在前，从尾往头 = 后入先出）：

```lua
-- 判定阶段：从尾往头逐张结算（后置入的先判）
local cards = zone:list()
for i = #cards, 1, -1 do
    if not player:isAlive() then return end   -- 死了就不再往下结算（阵亡清算还没做）
    local card = cards[i]
    if card:getZone() ~= zone then            -- 快照可能过期：不在了就跳过
        goto continue
    end
    New '延时锦囊结算' (game, player, card):apply():await()
    if card:getZone() ~= zone then            -- 结完自己挪走了（闪电判不中）就不弃
        goto continue
    end
    game:moveCard(card, '弃牌')
    ::continue::
end
```

- **无懈窗口正好在判定前**：`'效果-能否生效'` 由 `Effect:apply()` 在 `settle()` **之前**发 —— 即官方「生效前 = 判定前」。被抵消 ⇒ 不判定、不跑 `'判定结果'`，驱动把它送弃牌堆。
- **各阶段业务改为订阅 `'阶段-开始'`**（2026-09-28 收尾）：业务住 **`@基础/阶段/` 一个阶段一个文件**（判定 / 摸牌 / 出牌 / 弃牌），各自订阅；`runTurn` 只留六阶段循环 + 「回合」对象。

## 4）乐不思蜀：跳过出牌阶段

- 「跳过」的**机制**在 `@基础/回合.lua`：`runTurn` 建一个**「回合」对象**挂 `player.turn`（回合结束就没了，跳过**不会漏到下一个回合**），要跳过的阶段记在它身上（`turn:skipPhase` / `takePhaseSkip`）；回合循环每个阶段前读掉、命中就 `goto continue`（**连 `enterPhase` 都不进**）。
- 乐不思蜀的 `'判定结果'`：非红桃 ⇒ 往目标身上记一笔「跳过出牌」。
- 判定阶段记、出牌阶段读掉 ⇒ 正好是官方「跳过其**下一个**出牌阶段」。

## 5）闪电

- `'获取目标'` = `{ plan.user }`（对自己使用；「自己判定区已有闪电」由模板的同名过滤挡掉）。
- `'判定结果'`：
  - 黑桃 2~9 ⇒ `game:damage(nil, player, 3)`（**无来源**：`Damage.from` 空 ⇒ 奖惩不触发，`身份场/奖惩.lua` 已有分支）；牌留在判定区 ⇒ 驱动送弃牌堆（= 官方「造成伤害后弃置此牌」）。
  - 否则 ⇒ **自己**从 `desk:getNext(player)` 起找第一个**合法目标**（存活 + 判定区里没有闪电）并 `game:moveCard(card, 目标:getZone('判定'))`；找不到（只可能出现在 2 人局、两张闪电都在场）先按**进弃牌堆**处理，标为待官方 FAQ 校准。
- 传递不是通用驱动的行为：驱动只兜底「还在判定区 ⇒ 弃牌」，移走是闪电自己干的。

## 6）判定阶段的无懈窗口（改动点）

- `package/标准/卡牌/无懈可击.lua` 的 `'效果-能否生效'` 订阅多认一种 kind：`effect.kind == '延时锦囊结算'`（`effect.card`、`canNullify` 的「是锦囊」照旧）—— 其余（按行动顺序一圈、嵌套、奇偶）全部现成，不用碰。
- ~~使用期的抵消窗口本来就是现成的（模板的置入挂在 `'生效'` 上，被抵消自然不置入）。~~ **2026-09-28 更正：使用期不该有窗口**（官方不允许）——改造后模板的置入改挂 `'使用'` 并声明 `skipEffect`、不进窗口。

## 7）阵亡（本批只做一条）

- **阵亡清算**（判定区 / 手牌 / 装备的牌进弃牌堆）**本批不做** —— 整个记到以后的**「死亡规则」批次**（用户 2026-09-28 定）；死后的判定区里剩的牌留在原地。
- **回合内死亡 ⇒ 结束这个回合**（本批做）：`runTurn` 每个阶段前判一下回合角色还在不在，死了就 `break`（不再进后续阶段；`'回合-结束'` 照发 —— 与官方核对放在实现时顺手做）。

## 9）待确认（不阻塞本批）

1. 闪电找不到合法目标 ⇒ 先按进弃牌堆（等官方 FAQ 校准）。
2. 牌表整表张数 / 牌面核对（上线前统一排查，含本批两张）。
3. 「回合内死亡 ⇒ 结束回合」时 `'回合-结束'` 是否照发（先照发）。
4. 延时锦囊「判定阶段开始时」的时点顺序（技能接缝）—— 需要时再说。

## 10）本批不做

- 兵粮寸断（军争）与军争的判定区差异（上限 / 同名细则）。
- 判定区的技能交互（获得 / 移动判定区的牌这类技能）。
- **阵亡清算**（判定区 / 手牌 / 装备的牌进弃牌堆）—— 整个归「死亡规则」批次。
- 判定区里牌的**可见性**策略（现在默认可见 ✅ 符合官方）。

## 11）二次更正（2026-09-28，用户逐条复审后的最终形状）

> 以下推翻了上文若干处（上文保留为决策记录；最终形状以代码 + `sanguosha-rules` §9.12 为准）：

- **「使用」= 一次用牌一次**（不是逐目标）：原 `'结算前'` 钩子改名 **`'使用'`**（`UseCard` / `UseCardToCard` 在逐目标之前 fire 一次，载荷 = 这次用牌）；**「生效」只归 `CardEffect`**（使用期逐目标 / 判定阶段每张一次）—— `CardEffect` 不再跑「使用」段（use ↔ 使用、effect ↔ 生效，各归各的对象）。
- §2 的模板：置入改挂 **`'使用'`**（从 `useCard.targets` 取目标）并新增 **`: skipEffect()` 声明** ⇒ 这次用牌不发起「生效」（`UseCard:settle` 不建 `CardEffect`）、也**不进窗口**。「置入放 `'生效'`（被无懈就不置入）」作废：**使用期没有窗口**。
- §3 作废：`package/@基础/延时锦囊.lua`（`延时锦囊结算` 效果类）**已删**；判定阶段逐张调 **`Card:doEffect()`**（**内核方法**，`server/core/card.lua`：找区主人 → 建判定期 `CardEffect` → 驱动）；判定与效果都由牌自己的 `'生效'` 写（`'判定结果'` 从未落地）。
- §5 的闪电传递：实现用**行动顺序迭代器**（`desk:actionOrder`，见技能 §9.12）。
- **牌钩子 `'结算后'` 删除**（2026-09-28，收尾）：它唯一的用户「装备牌」模板改挂 `'使用'`（装备在「使用」钩子里放进装备区）；固定集合收敛成五个（`'进入区域'` / `'获取目标'` / `'获取卡牌目标'` / `'使用'` / `'生效'`）。
- §6 的无懈 kind：判定阶段那次就是 **`'cardEffect'`**（不新增 kind）；使用期不进窗口。
- 附带（同批复审）：建牌**必给非空字符串牌名**（`setName` / `resolveDef` 删）、`Effect.refusable` 补丁删（使用期不建效果 ⇒ 窗口问题消失）。
