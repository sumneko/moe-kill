# Proposal

## Why

标准包的内容做到「八张武器 + 六张坐骑 + 十张非延时锦囊」之后，**延时锦囊还没做**：

- 牌表里没有它们（`package/标准/牌表.lua` 顶部就注着「还没有延时锦囊（乐不思蜀 / 闪电）」）；
- `@基础/回合.lua` 的**判定阶段是空转**（只进 / 出阶段，不结算任何东西）；
- 玩家的 `判定` 区（内核建好的五个基础区之一）**从建成起就没放过牌**。

延时锦囊这一批要干的事就是**把判定区真正用起来**：使用 → 置入目标的判定区 → 该角色的**判定阶段逆序结算**（后入先出）→ 判定结果决定后果 → 牌进弃牌堆（闪电例外：传给下家）。

顺带会第一次用上几个刚落地/刚放宽的能力：

| 要用到 | 现状 |
| --- | --- |
| 判定动作 | ✅ `game:judge(player, reason)`（`@基础/判定.lua`，结果读 `.card`） |
| 无来源伤害（闪电 3 点） | ✅ `Damage.from` 刚放宽成可空 ⇒ `game:damage(nil, 目标, 3)`；奖惩那边「凶手为空 ⇒ 不奖惩」也已就位 |
| 逆序取判定区的牌 | ✅ `判定` 是 `OrderedZone`（`list()` / `take(下标)`） |
| 「对一张牌使用」（使用期 / 判定阶段问无懈） | ✅ `canUseToCard` / `useCardToCard` / `askUseCardToCard` + `'获取卡牌目标'`（【无懈可击】已声明认锦囊）；判定阶段那一种要补认一个 `kind`（见 design） |
| 触发时机的插入点 | 波波攒够了：`'阶段-开始'` / `'阶段-结束'` 已由 `enterPhase` 发 |

## What Changes

- **`package/@基础/回合.lua` 的判定阶段真的结算**：对本回合角色的判定区**逆序**（后置入的先判）逐张结算；每张的流程 = **判定前问无懈 → 进行判定 → 牌自己按结果处理**。
- **新增 `package/@基础/延时锦囊.lua`**：结算效果 `延时锦囊结算`（一次结算 = 一个效果，被无懈抵掉就不判定）+ 驱动（逆序 / 逐张 / 收尾送弃牌）+ 阵亡清理判定区。
- **`package/@基础/卡牌/锦囊牌.lua` 里新增 `延时锦囊牌` 模板**（`: extends '锦囊牌'` + 分类覆盖）：`'获取目标'` 里做「判定区同名」的通用过滤、`'生效'` 把牌置入目标判定区（被无懈 ⇒ 不置入）。
- **两张标准版延时锦囊**：乐不思蜀（判定非红桃 ⇒ 跳过**下一个**出牌阶段）与闪电（判定黑桃 2~9 ⇒ 3 点**无来源**雷电伤害；否则**自己**找下一个合法目标移动过去）。
- **「跳过阶段」= 该阶段不发生**（不进阶段，`'阶段-开始'` / `'阶段-结束'` 都不发 —— 官方口径），机制放 `@基础/回合.lua`。
- **延时锦囊的无懈窗口补齐**：使用时（现成）与**判定阶段结算每张时（判定前）**（新做，逐张）。
- **回合内死亡** ⇒ `runTurn` 每阶段前判存活、死了就结束这个回合（闪电会打死回合角色）；**阵亡清算**（判定区 / 手牌 / 装备的牌进弃牌堆）记到以后的「死亡规则」批次，本批不做。
- 牌表补上这两张的条目（乐不思蜀 ♠6/♥6/♣6 ×3；闪电 ♠A + EX ♥Q，按 biligame wiki 先录，上线前统一核对）。

## Capabilities

### New Capabilities

无。探索期的架构决策记录，不写规格增量（`.openspec.yaml` 设 `skip_specs: true`）。

### Modified Capabilities

无（同上）。

## Impact

- `package/@基础/回合.lua`（判定阶段调驱动；跳过阶段；回合内死亡）
- `package/@基础/延时锦囊.lua`（新：结算效果 + 驱动）
- `package/@基础/卡牌/锦囊牌.lua`：新增 `延时锦囊牌` 模板（与 `锦囊牌` 同文件）
- `package/@基础/meta.lua`（`'判定结果'` 钩子与结算效果的类型注解）
- `package/标准/卡牌/{乐不思蜀,闪电}.lua`（新）、`package/标准/卡牌/无懈可击.lua`（窗口多认一种 kind）、`package/标准/牌表.lua`
- 用例：`server/test/rule/`（新套件或并入 `rule.trick`）
- 文档：`sanguosha-rules`（§9.3 牌表清单、§9.8 判定阶段、§9.10 无懈窗口、新增延时锦囊一节）、`moe-kill-dev` 的 `progress.md`

## Non-goals

- **兵粮寸断**（军争篇）与军争的判定区差异（上限 / 同名细则）。
- **判定区的技能交互**（改判已落地；「获得/移动判定区的牌」这类技能将来再说）。
- **阵亡清算**（判定区 / 手牌 / 装备的牌进弃牌堆）—— 整个记到以后的「死亡规则」批次。
- **闪电的极端细节**（找不到合法目标时先按弃置；洗牌时闪电在哪、牌堆耗尽时的处理）—— 碰到再定。
- 内核一行不改（判定区、`judge`、`moveCard`、`damage` 都现成；新钩子 `'判定结果'` 走 `CardDef` 的自由事件名 + 内容侧自跑 ⇒ 本批是**内容侧**的一批）。
