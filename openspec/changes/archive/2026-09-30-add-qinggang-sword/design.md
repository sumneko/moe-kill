# Design

## 1）官方文本与裁定（依据）

> 牌面（标准版）：「锁定技，当你使用【杀】指定一名角色为目标后，无视其防具。」
> 裁定一（§1 司马懿条）：「……是装备【青釭剑】的太史慈使用的火【杀】的目标。首先对司马懿进行结算，司马懿在受到 1 点火焰伤害后（**此时【青釭剑】对司马懿的效果结束**）……虽然太史慈失去了【青釭剑】这个技能，但是**【青釭剑】对崔琰的效果不会消失**……」
> 裁定二（§7）：「装备【青釭剑】的角色 A 对 B 使用【杀】，在【青釭剑】的效果持续时间内，任何角色弃置或获得 B 装备区里的【白银狮子】，B 在失去【白银狮子】前 -2 均不能发动【白银狮子 2】。」

两条口径：① 窗口**按目标**结束（该目标那次生效结完）；② 窗口**不随剑 / 使用者消失**（压在使用开始时对全目标一次性做完）。

## 2）时机：压 / 松 / 兜底

| 环节 | 时点 | 做什么 |
| --- | --- | --- |
| 压 + 兜底 | `'卡牌-结算前'`（使用结算开始时，逐目标之前） | 状态订阅挂在**使用者头上**（`owner:on('卡牌-结算前')`，2026-09-30 补的第二个发出点）；对**全目标**：`useCard:bindGC(target:addBuff('防具无效', useCard))` —— 状态挂给**这次使用**（载荷），那次使用收场（含半路取消 / 目标没轮到生效）效果被删 ⇒ 状态跟着被删 |
| 松 | 每个目标的 `'效果-收尾'`（状态自己在 `'获得'` 里订 `buff.owner:on('效果-收尾')`；只比 `effect.useCard == 载荷里的那次使用`） | `buff:remove()`（→ 撤销子区禁用） |

- **压不在来源段逐目标做**：那样会漏掉「乙结算里剑被拿走 / 使用者死亡」之后的丙（裁定一）。
- **松不放在整次使用的收尾**：官方对每个目标分开（「对司马懿的效果结束」在轮到崔琰之前）。
- **兜底用「状态挂给这次使用」而不是订一次收尾**（2026-09-30 定）：`useCard:bindGC(buff)` 让效果被删时连带删掉状态（`GCHost:bindGC` 收 table），比订 `'效果-收尾'` 再自比 `effect == useCard` 少一条订阅。
- **压制交给子区 + buff**：不记「目标 → 那张防具牌」—— 窗口内换装（进被禁子区）自动无效、拆装也不用追；buff 只是把这个窗口变成可见、可查、可收的对象。

## 3）效果收尾闸门（**已于 2026-09-29 提前单独落地，本变更不再包含**）

`'效果-收尾'` 原来只在「结完时自己建过临时区」的效果上发；没人应答【闪】的那次生效不建区 ⇒ 发不出来 ⇒ 松不了手。⇒ 去掉闸门（**每个效果都发一次**），内容侧自己按载荷过滤（本变更里唯一的订阅者是青釭剑的 buff）。同时：默认收尾的弃牌改批量 `discard:accept(zone:list())`（`Zone:accept` 本来就是批量入口）。

**实测补记（落地时踩到）**：去掉闸门后收尾是**可重入**的 —— 处理器里起的结算（`game:moveCard` / `game:damage`…）结完时同样发收尾，不按载荷过滤就会一层套一层自激（内核有兜底：越限那层不结算也不发收尾，链停在 150 层、不会爆栈，但会白造上百层空结算）。⇒ 本变更的 buff 订阅仍要写全过滤条件（`effect.useCard == 这次使用`），且 `buff:remove()` 里不要再起结算。**2026-09-30 补**：`'效果-收尾'` **在承受者头上也发一份**（`effect.to?:fire`，与 `'效果-目标-能否生效'` 同一口径）⇒ 状态可以直接订 `buff.owner:on('效果-收尾')`，不用再比 `effect.target == buff.owner`；`useCard` 那一半仍然要留（同一个人的别的结算也会从他头上发过来）。

## 4）已知边界（写清，别默默略过）

**窗口内失去防具、其「失去时」技能仍不能发动**（裁定二）做不到：牌一离开子区，区级那层压制就松了（`rework-zone-disable` 的离区口径）。军争牌（【白银狮子】等）到齐时再定怎么补 —— 可能是「buff 记牌、离区时也不松」这类形状。

## 5）用例（`rule.equip`）

1. 常规：剑主用黑【杀】打装备【仁王盾】的目标 ⇒ 不被抵消、造成伤害；这次使用收尾之后【仁王盾】恢复（**换旁人**再一张黑【杀】照旧被抵消 —— 同一个剑主再打还是无视防具）。
2. 对照：没装【青釭剑】（或旁人用【杀】）⇒【仁王盾】照常生效。
3. 裁定一复刻：一次【杀】两个目标，第一个目标结算里把剑搬走（模拟【反馈】/死亡）⇒ 第二个目标仍被无视。
4. 换装：窗口内把目标的防具换掉（旧牌进弃牌堆、装上一张新的）⇒ 新的照样无效。
5. 半路收场：这次使用被取消 / 目标没轮到生效 ⇒ 收尾兜底把 buff 清干净（不残留永久压制）。
