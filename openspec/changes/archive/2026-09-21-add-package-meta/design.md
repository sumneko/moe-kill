# Design

## D1 名字叫 `meta`（用户 2026-09-21 定）

项目约定「包名与包内文件名用中文」，但这一份**不按内容命名**：它是**纯代码功能**（给编辑器看的类型声明），不是规则内容。名字固定 `meta`，与内核的 `env-meta.lua` / `env-util.lua` 同一路数（`env-` 前缀的那两份是内核侧的同类物）。

## D2 装载器不特殊对待它

`meta.lua` 就是包目录下的一个普通 `.lua` 文件 ⇒ 装载器照常执行它。里面只有注释，执行是空操作（实测全量 354 用例全绿）。于是：

- **不引入**「跳过某些文件」的新机制（装载器的行为面越小越好）；
- 代价：它会出现在 `loadedFiles` 与包元信息里 —— 可接受，而且反过来证明「它确实是个普通文件」。
- 约束（写进文档）：**`meta.lua` 里只放类型声明**（`---@meta` + `---@alias` / `---@field`）。放了真代码就会被执行。

## D3 配方与坑（实测）

**配方**：`---@meta` 开头 → 用 `---@class` **重声明**内核类（基类必须写全，如 `---@class Player: Class.Base`）→ 逐条写**收窄**签名 → **最后再写一条兜底签名**。

**坑（踩过一次）**：只写收窄那一条时，**内核原来的签名会被吃掉** —— 全仓 27 处 `getTag('顺序')` / `setTag('某表', …)` 立刻报「不能将 `string` 赋给参数 `'身份'`」。原因：跨文件重声明同名 `---@field` 不是叠加，而是**接管这个名字的签名表**；内核那份来自方法定义（`---@param key string`）的签名会被替换掉。所以**兜底必须自己再写一遍**（`env-meta.lua` 里 `Game.on` 之所以没这个问题，正是因为它的兜底本来就是它自己写的）。

**已验证的良性质**：

- **多个包各自声明同名 `---@field` 会共存** —— `'主公额外体力'|'默认体力'`（`@基础`）与 `'身份配置'`（`身份场`）同时对 `game:getValue` 生效；
- **跨包读也生效** —— `身份场/开局.lua` 里读 `@基础` 的 `主公额外体力` 拿到了 `integer`；
- **字段名并集**：重声明不会把内核那份类声明里的其他字段弄丢（hover 实物可见）。

## D4 收窄的边界

只声明「内容侧真的会传字面量」的名字，并**始终留兜底** ⇒ 动态名字照旧走 `string` 那条（否则会误报）。这与 `env-meta.lua` 里「局的时机是开放集合、必须留 `string` 兜底」是同一条口径。

属性的取值类型统一写 `number`（不写 `integer`）：`addAttr('体力', -damage.amount)` 这类算术里 `amount` 未必被标注成整数，写 `integer` 会制造无谓的误报。

## D5 「包作者可见的类型面」变成两处

以前文档说「接口面就是 `env-meta.lua`」，现在要改成：

- **内核的通用面**（注入的 `game` / `Card` / `Depends` / `util`、各时机上下文）⇒ 仍在 `server/core/loader/env-meta.lua`；
- **各包自己的概念**（身份、规则数值、牌表结构、自有标签）⇒ 包目录下的 `meta.lua`。

**第三方包**：允许也自带 `meta.lua`（用户 2026-09-21 定：「允许，我们也阻止不了」）。文档按「包作者契约」写，而不是「本项目内部约定」。

## D6 不做：便捷函数（用户 2026-09-21 定「遇到再说」）

用户初步设想是「**允许包直接定义全局函数**（所有 package 文件共享一个专用 env，`__index = _G`）」。真要开的时候有一条**硬约束**要记住：

> `---@` 现注入的环境是**自建 env**（`load(chunk, '@'..路径, 't', env)`），所以内容侧看不到 `moe` / `require` / `io` / `os`。一旦 `__index = _G`，`moe` 是全局变量 ⇒ **沙箱当场漏掉**（`require` / `io` / `os` 同样是全局）。

⇒ 若目标只是「**包与包之间**共享函数」，`__index` 应该指向**装载器建的一张共享的「内容函数表」**（所有包共用、由装载器持有并在重装时清空），而不是 `_G`。那时的形态更像「内容侧的服务表」：加载期登记、运行期可调用、随装载清空。**本批不做**。
