# Proposal

## Why

【闪】的响应现在要**业务层自己把牌挪走**（`package/标准/卡牌/杀.lua` 里那句 `game:moveCard(card, { '处理', '弃牌' })`），但「打出的牌去哪儿」本来是**基础规则**该管的事 —— 它也已经在管（`'卡牌-打出后'` 把牌放进 `弃牌`），于是同一张【闪】被挪了两次：先被基础规则扔进 `弃牌`，再被内容包挪「处理 → 弃牌」。

根因是两件事缺位：

1. **询问没说清"要这张牌干什么用"** ——「打出一张【闪】」与「交出一张牌」在内核眼里一模一样，规则层没有依据去接手这张牌的去向；
2. **挪牌还不是效果** —— 只能一张一张地做，没有结算、不能挂时机、也不能被取消或替换。

## What Changes

- **挪牌提成效果**：新增 `MoveCard : Effect`（`kind` = `moveCard`），**一次结算挪一批牌**（沿给定路径，见下），天然进结算栈、触发「即将生效」、可被取消；`game:moveCard(card, zone)` 变成「造效果 + 驱动 + 等」的**便利入口**并返回效果实例（与 `game:damage` / `game:useCard` 一致）。**BREAKING**（对内）：挪牌失败不再上抛，改为记在 `.err` 上（与其它效果一致）。
- **询问带上「为什么问」**：`game:askCard(被问者, reason, 要什么牌)` —— 第二个参数 `reason` 是不透明字符串（`'打出'` / `'使用'`…，**内核不解释取值**，只原样转给规则层）。
- **答复后触发一个时机**：询问结束后由局触发 **`'卡牌-答复'`**（与 `'卡牌-询问'` 对称；时机名的分类是「卡牌」），上下文 = 这次询问实例（被问者 / `reason` / 给出的那张牌）⇒ 规则层据此决定"这次答复意味着做了什么"。
- **基础规则接管去向**：订阅 `'卡牌-答复'` —— `reason` 为 `'打出'` 且给出了牌 ⇒ 用**询问实例上的 `:respond()`** 把这次答复当作一次「打出」，并让它经 `处理` 送进 `弃牌`。⇒ **业务层（内容包）再也不写 `moveCard`**，【杀】的响应只剩「读 `.result`、按结果决定是否受伤」。
- **顺带同步过期的规格**：`core-response` 的描述还停在旧模型（外部注入的"回答者"、"拿不出答案 ⇒ 明确失败"），与现状（询问走 `'卡牌-询问'` 时机、**没人答上不是失败**）相反 —— 一并改掉（那批代码改动当时没走变更）。
- **时机改名**：「游戏-询问」→ **`'卡牌-询问'`**（分类与其他卡牌时机一致），新时机叫 **`'卡牌-答复'`**。
- 本批**不做**：处理区的**停留点**（打出的牌一次走完「处理 → 弃牌」；真出现"看得见处理区"的牌或技能时再定停留时机）、「移动前 / 后」这类专有时机（需要时再加，`'即将生效'` 已经能拦）、`reason` 的取值枚举与校验（内核不预设；用户 2026-09-20 定：**先不写进类型声明**，等缘由多起来再说）。

## Capabilities

### New Capabilities

（无 —— 都是既有能力的行为演进。）

### Modified Capabilities

- `core-move`: 挪牌从「一次函数调用」变成**效果** —— 一次结算挪一批牌、可被取消、失败记 `.err`；`game:moveCard` 成为便利入口并返回效果实例。
- `core-response`: 询问加 `reason`；「游戏-询问」改名 `'卡牌-询问'`、新增 `'卡牌-答复'` 时机与 `询问:respond()`（把答复当作打出）；**反向同步**掉过期的「回答者 / 拿不出答案即失败」描述。
- `base-rules`: 基础规则据 `reason == '打出'` 自动完成「打出」与去向（经 `处理` 进 `弃牌`），业务层不再挪牌。

## Impact

- 内核：`server/core/move-card.lua`（新）、`server/core/ask-card.lua`（加 `reason`、答复后触发时机）、`server/core/game.lua`（`moveCard` 变便利入口、`askCard` 签名）、`server/core/init.lua` 与 `server/moe-kill.lua`（挂 `moe.moveCard`）、`server/core/loader/env-meta.lua`（新时机与签名）。
- 内容：`package/@基础/牌堆.lua`（订阅 `'卡牌-答复'`；打出后走「处理 → 弃牌」）、`package/标准/卡牌/杀.lua`（删掉 `moveCard`）。
- 测试：`server/test/core/game.lua`（挪牌失败断言从"抛错"改成"效果失败"）、`server/test/core/ask-card.lua` 与 `server/test/rule/{slash,support}.lua`（询问多一个 `reason` 参数）。
- 文档：`moe-kill-dev/references/architecture.md` §12（挪牌效果、答复时机）、`sanguosha-rules` §6 / §7 / §9.2（打出由 `reason` 驱动、业务层不写 `moveCard`）。
