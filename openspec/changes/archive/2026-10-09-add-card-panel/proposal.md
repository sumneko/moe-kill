# 变更：面板（`Panel`）与 `askPanel`

## 需求

新增一个一等概念「**面板**」：**一批牌摊开成若干行，可以在上面「选择 / 移动」，可以标记与禁用，可以被多次询问共享**；配一个询问入口 **`askPanel`**（一次询问一直开着，直到客户端点「确定」为止）。

两个消费者：

1. **【观星】**：换掉现在的**服务器暂定占位分配**（逆序置顶），改成玩家的答复（把观看的牌分到「牌堆顶 / 牌堆底」两行）。
2. **【五谷丰登】**：改成共享面板（亮出的牌摊一行，每人挑一张 ⇒ 挑走的 `disableCard` + `addMark` 记谁拿的），并按底本「每名目标角色**获得**其中一张」补上**兜底**：没答（超时之类）⇒ 服务器替他拿**第一张没被禁用的**。

## 为什么

- 现在「一批牌摊开、在上面做选择」**没有一等概念**，只能靠两样凑：① 借「牌在哪个区」表达状态（五谷丰登靠「被拿走的牌已离开临时区」隐式排除，界面没法表达「谁拿走了」）；② `AskCard.Condition` 全是**逐张**判据，表达不了「把这批牌**怎么摆**」（观星要分两堆 + 每堆有序 ⇒ 只能靠服务器占位）。
- 归到底它们**是同一族**：观星（排列 / 分堆）、五谷丰登（共享挑选）、将来【称象】那类（从亮出的牌里挑一个**满足整体约束**的子集）都属于「一块共享的牌面 + 若干次选择」。
- 协议层也需要一份声明：「这块面板现在长什么样、哪些牌还被允许动」⇒ 这是**对外契约**（有外部消费者）⇒ 本变更**写 `specs/` 增量**（不设 `skip_specs`）。

## 做什么

1. **内核**：`Panel`（`createPanel` 全局；行 / 标记 / 禁用 / `isDisabled` 查询 / 可见性 / `GCHost` 寿命）+ `AskPanel`（`game:askPanel` + `'面板-询问'` 时机 + **变化值校验**）+ `Game` 入口 + `env-meta` 类型面。
2. **内容**：【观星】改成面板版（`min = 0`、两行、`moveable`）；【五谷丰登】改成面板版（`min = 1`、一行、`disableCard` + `addMark` + 兜底）。
3. **用例**：内核（`Panel` 的行 / 禁用 / 标记 / 可见性；`AskPanel` 的变化校验、`min` 校验、`done` 收尾、result 形状）+ 观星（改成按答复放回）+ 五谷丰登（共享面板 + 兜底）。
4. **协议（`specs/` 增量）**：面板的表示 + 一次询问的往返（变化 → 校验 → 状态更新 → 直到确定）。
5. **文档**：`architecture.md`（`Panel` / `askPanel` 行、`'面板-询问'`）、`sanguosha-rules`（§9.33 观星改成面板版；五谷丰登的口径 + 兜底）、`progress.md`。

## 不做什么

- **不改【遗计】**（用户 2026-10-09 定）：它继续用自己的写法。
- **不把既有 `askCard` 族重写成面板**（用户定）：其他 ask 系列由**客户端**自己做一块通用面板（或服务器内部封装成 `Panel`），内核不动它们。
- **不动区级可见性**（用户定）：面板管的是「牌面遮不遮」，与区无关 —— 牌丢进弃牌堆用户可以自己看，临时区同理，都照旧 `setVisible`。
- **不改 `cancelable` 的语义**（用户定）：面板与 ask 系列保持同一套字段。
