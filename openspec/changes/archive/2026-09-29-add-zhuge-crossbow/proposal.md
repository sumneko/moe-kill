# 诸葛连弩：「次数修正」与无限【杀】

## Why

装备技能的第三张、也是最常用的一件。选它的理由：**机制依赖最小** ——「次数修正」是「目标数修正」（2026-09-29 刚做）的孪生兄弟：collect 式修正事件、`checkCardItself` 收口、`+1000 = 不限` 的既有口径全都现成；其余装备的依赖都更大（青釭剑要「技能压制」新件、八卦阵要「替换 / 追加一次响应」、雌雄双股剑要性别、丈八蛇矛要「转化」、贯石斧 / 青龙偃月刀要「被【闪】抵消后」的接缝、麒麟弓要伤害归因）。

## What Changes

- **内核加一次修正收集**：`checkCardItself`（`canUse` 与 `canUseToCard` 共用的收口）里，限额从 `def:getLimit(阶段名) + phase:getLimitDelta(名字)` 扩成 **再加 Σ `'卡牌-次数修正'`（载荷 `user` / `card`）** —— 各来源各贡献一个整数增量（可正可负）。
- **事件声明**：`env-meta.lua` 加 `Game.Event.卡牌次数修正` 与 `Game.on` 的收窄（放「卡牌-目标数修正」旁）。
- **【诸葛连弩】**（`package/标准/卡牌/诸葛连弩.lua`）：『被动』订阅 `'卡牌-次数修正'` —— 装备主使用【杀】 ⇒ 返回 `+1000`（既有口径「+1000 相当于不限」）。

## Non-goals

- 其余 8 件装备技能（各自是一个功能点）；
- 「修正」的按玩家定向（与 `'卡牌-目标数修正'` 保持同款：局级 collect + 回调自认 `check.user`），若要改成 `user:collect` 两处一起另议。
