# Design

## Context

- **用牌这条链**（`server/core/effect/use-card.lua`）：`canUse` 校验 → 内核记一次次数 → 从使用者名下牌区取牌 → 全局时机 `'卡牌-结算前'`（基础规则把牌放进 `处理`）→ **逐目标 `'生效'`**（顺序 = `desk:actionOrder(目标)`，起点是**顺序锚点**）→ 全局时机 `'卡牌-结算后'`（基础规则把牌送进 `弃牌`）。
- **牌定义的钩子**只有两个：`'获取目标'`（算合法目标时 + 用牌时都调）、`'生效'`（每个目标一次，ctx = `CardEffect`）。
- **已经能用的能力**：`game:heal` / `game:damage` / `game:askCard`（询问带选项、答复必须落在选项里；`'打出'` 的牌由基础规则送 `处理` → `弃牌`）/ `game.moveCard` / `desk:actionOrder` / `desk.alivePlayers`。
- **两张牌的官方原文**（规则集 5.2）：
  - 【桃园结义】使用时机：出牌阶段；使用目标：**所有角色**；作用效果：目标角色回复 1 点体力。◆对未受伤的角色无效。
  - 【决斗】使用时机：出牌阶段；使用目标：**一名其他角色**；作用效果：**由目标角色开始**，其与你轮流打出【杀】，直到其中的一名角色未打出【杀】。然后**未打出【杀】的角色受到另一名角色造成的 1 点伤害**。
- **还没做的能力**（本批刻意不碰）：【五谷丰登】（要两个牌钩子 + 一种候选来源，见 proposal 的 Why）、选**别人区域里**的牌（过河拆桥 / 顺手牵羊，牵扯信息可见性）、逼别人使用【杀】（借刀杀人）、嵌套询问窗口（无懈可击）、判定区（延时锦囊）。

## Goals / Non-Goals

**Goals:**

- 两张牌真的能用出去，且**逐条对上官方原文**：目标集合、"未受伤无效"、谁先打【杀】、谁挨打、打出的牌去哪儿。
- **内核一行不改**（这正是选这两张的理由）。
- 目标集合的写法（`alivePlayers`）与"回复"这条效果链第一次跑通。

**Non-Goals:**

- 【五谷丰登】—— 另开变更（它要的牌钩子与候选来源只为它服务，不该混在这批里）。
- 无懈可击、过河拆桥 / 顺手牵羊、借刀杀人、延时锦囊与判定区、锦囊的前端表现。
- 不做「使用结算开始时检测此牌对目标的有效性」这套机制（官方的『无效』本批只以"回复 0 点"体现）。

## Decisions

### D1 【桃园结义】：目标 = 所有存活角色，"未受伤无效"落到效果上

```lua
Card '桃园结义'
    : extends '锦囊牌'
    : on('获取目标', function (ctx)
        return game.desk.alivePlayers
    end)
    : on('生效', function (ctx)
        game:heal(ctx.target, 1)
    end)
```

- 官方「使用目标：所有角色」= 场上**存活**角色 ⇒ 用 `game.desk.alivePlayers`（含使用者自己）；**不**预先排除满血者（官方目标就是"所有角色"）。
- 官方把"无效"放在『使用结算开始时检测此牌对目标的有效性』。本批**不**做这套机制（它属于无懈可击 / 防具那批）⇒ 落到效果上：`game:heal(target, 1)`，满体力者回复 0 点（`Heal` 受体力上限钳制），可观测结果与官方一致（体力不变）。
- 用完的牌按基础规则的既有路径进 `弃牌`（内容侧不写 `moveCard`）。

### D2 【决斗】：由目标先开始，轮流打【杀】

```lua
Card '决斗'
    : extends '锦囊牌'
    : on('获取目标', function (ctx)
        return table.filter(game.desk.alivePlayers, function (player)
            return player ~= ctx.user
        end)
    end)
    : on('生效', function (ctx)
        local attacker = ctx.user
        local defender = ctx.target
        while true do
            if not game:askCard(defender, '打出', { name = '杀' }).card then
                game:damage(attacker, defender, 1)
                return
            end
            attacker, defender = defender, attacker
        end
    end)
```

- 官方「**由目标角色开始**」⇒ 第一轮问的是 `ctx.target`；每轮两人互换角色，直到有人没打出【杀】；没打出来的那个受**另一方**造成的 1 点伤害（`game:damage(另一方, 未打出者, 1)`）。
- 打出的【杀】的去向由基础规则接管（`'卡牌-答复'` → `处理` → `弃牌`），内容侧一行 `moveCard` 都不写。
- 循环出口：`askCard` 没有答复 ⇒ 结束（手牌有限 ⇒ 必然结束，不需要额外计数上限）。

### D3 目标集合用 `alivePlayers`

`desk.players` 含阵亡者，而官方"所有角色"/"一名其他角色"都只指存活角色 ⇒ 桃园结义用 `alivePlayers`；决斗用 `table.filter(game.desk.alivePlayers, …)` 排掉使用者（与【南蛮入侵】【万箭齐发】同一个写法）。

### D4 验收方式

用例（`server/test/rule/trick.lua`）钉四件事：

1. **桃园结义**：受伤的（含使用者自己）各回 1 点、满体力的不变、用过的牌进 `弃牌`。
2. **桃园结义的合法目标**：所有存活角色，**含自己**。
3. **决斗**：先问**目标**（记录被问顺序）、双方各打一张后目标打不出 ⇒ 目标挨 1 点且来源是使用者、打出的【杀】进 `弃牌`；目标手上没【杀】就直接挨打。
4. **决斗的合法目标**：其他存活角色，不含自己。

外加把两张牌并入既有的分类用例（`isKind('锦囊')` / `isKind('非延时锦囊')` / 从 `手牌` 用）。

## Risks / Trade-offs

- [决斗里两人可以来回打很多张【杀】] → 每轮走一次询问（同一次用牌的结算，不算嵌套）；手牌有限，不会无限循环。
- [桃园结义对满血角色也"结算"了一次] → `Heal` 结算照走、回复 0 点，与官方的"无效"在可观测结果上一致；将来若接了"有效性检测"，要改的只是 `'获取目标'`（那时它才需要排除满血者）。
- [两张牌都只动内容侧] → 没有内核风险；用例全绿即契约成立（探索期以用例为准）。
