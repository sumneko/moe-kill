# Spec Delta

## ADDED Requirements

### Requirement: 默认加载的包

带**默认加载标记**（来源目录名以 `@` 开头，见 `package-vfs`）的包 SHALL 由加载器自动加入本轮加载，调用方**不必**把它写进清单；自动加入的这些包 MUST 排在**清单项之前**，它们之间的顺序 SHALL 按逻辑包名确定（保证同一份来源下顺序稳定）。清单里**显式**写了默认包时 SHALL 仍然只执行一遍（与「同一文件只执行一次」一致）。

默认包 MUST 用**不带 `@` 的逻辑名**参与一切引用与查询：清单项、依赖项（含相对路径）、限定名（如 `标准.杀`）、包元信息里的包名。加载器 MUST NOT 提供「按名字关掉某个默认包」的开关 —— 要排斥它 SHALL 用互斥声明（`rule.depends { '!基础' }`）。

#### Scenario: 不在清单里也会被加载

- **WHEN** 清单只写了其它包，而来源里有一个带标记的包
- **THEN** 这个包的文件同样被执行（例如它注册的「游戏-开始」回调照常触发）

#### Scenario: 默认包排在清单之前

- **WHEN** 清单写了若干项，来源里还有带标记的包
- **THEN** 带标记的包的文件先执行，清单项的文件后执行

#### Scenario: 引用时不写 @

- **WHEN** 某个包依赖带标记的基础包，并查询它的包元信息与限定名
- **THEN** 依赖项、限定名与元信息里的包名都是不带 `@` 的名字（如 `基础`、`基础.杀`）

#### Scenario: 显式写进清单也只执行一遍

- **WHEN** 清单里显式写了默认包，同时它又会被自动加入
- **THEN** 该包的文件本轮只执行一次
