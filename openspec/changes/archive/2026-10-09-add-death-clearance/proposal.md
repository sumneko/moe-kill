# 提议：阵亡清算（死亡后清空死者的牌）

## 为什么

这是「死亡规则」里最后一块：官方口径是角色死亡后其所有牌置入弃牌堆（手牌 / 装备区 / 判定区）。现在死后死者的牌**留在原地** —— 判定阶段为此留了一层临时措施（「回合角色死了就停」），而且死者的判定区里躺着的延时锦囊再也不会被处理。

## 改什么

- **内容**：新增 `@基础/阵亡.lua`，订阅 `'玩家-死亡'`：
  1. **先把死者身上的技能全部停用**（`skill:disablePassive()`）—— 否则下面这批牌离区时，死者的技能（如【枭姬】）还会响应（官方明文：已死亡的角色不能发动技能，`Ch1/S2:46` 的吕布例）；
  2. 把死者**所有牌区**里的牌照单，一次 `game:moveCard(cards, '弃牌')` —— 手牌 + 判定 + 四个装备子区，将来内容侧加的区自动跟上。
- **顺序**：`@基础` 是默认包、排在清单项之前 ⇒ 它的 `'玩家-死亡'` 处理器**先注册先跑** ⇒ 清算 → 奖惩 → 胜负判定（官方 `Ch1/S2:64`：死亡时先亮身份 → 各技能时机 → **最后**来源执行奖惩）。
- **撤掉一层临时措施**：`@基础/阶段/判定阶段.lua` 里「回合角色死了就停」的提前退出（注释写明「阵亡清算做了之后这层可撤」）。

## 不做什么

- 不做「已死亡的角色不能发动技能」的通用机制（内核分发处判存活）—— 本批只在清算这一处停用技能；将来真需要再单独规划。
- 不动协议层（死亡的牌怎么展示给前端）。
