# Design

## Context

- 伤害住在 `package/@基础/伤害.lua`（`Damage` + `game:damage`）；`settle()` 现在直接扣体力、≤0 进濒死、末尾发 `'伤害-结束'`。
- 官方把伤害事件分成几段时机：**造成伤害时-1/-2/-3 → 受到伤害时-1/-2/-3 → 扣减体力 → 受到伤害后…**。麒麟弓在官方例子里直写「造成伤害时-2」（与古锭刀 -1、寒冰剑 -2 同批）。
- 依据（规则底本）：
  - Ch1/S1：寒冰剑例 —— 造成伤害时-2「若发动【潜袭】…则终止此伤害流程」⇒ 尚未扣血；
  - Ch2/S7：寒冰剑在造成伤害时-2「防止此伤害即终止此伤害流程」；
  - Ch2/S5：古锭刀在造成伤害时-1 改点数，之后才「A 受到 2 点火焰伤害」；
  - Ch2/S9：扣减体力是伤害事件里靠后的子事件（「扣减体力前」「伤害事件中产生的扣减体力事件」）。
- 牌区侧：目标的坐骑在 `进攻马` / `防御马` 两个子区（分类「坐骑」）；候选给 `askCard` 的 `card` 条件（【五谷丰登】先例）、「弃置别的角色的牌」的问法有【过河拆桥】先例（问使用者、候选来自目标）。

## Goals / Non-Goals

**Goals:**

- 伤害在扣体力之前有个正式触发点：全局 `'伤害-开始'` + 来源 `'伤害-来源-开始'`（命名对齐「效果-来源-能否生效」的标法；承伤侧将来叫 `'伤害-目标-开始'`）。
- 麒麟弓：本人使用【杀】对目标造成伤害时，可以弃其一张坐骑牌。

**Non-Goals:**

- 受到伤害时（`'伤害-目标-开始'`）、防止 / 修改伤害、转移 / 连环、其余装备技能。

## Decisions

### D1. 两个时机的落点与发出方式

```lua
function Damage:settle()
    local to = self.to
    -- 伤害流程开始（= 官方「造成伤害时」，在扣体力之前）：全局一份、来源一份
    self.game:fire('伤害-开始', self)
    self.from?:fire('伤害-来源-开始', self)
    to:addAttr('体力', -self.amount)
    ...
```

- 全局先、当事人后（「阶段-开始」「卡牌-结算前」「效果-收尾」的既有先例）。
- 分两个名字（不是同名再发一份）：来源 / 目标的标法已有先例（`'效果-来源-能否生效'` / `'效果-目标-能否生效'`），同名会让将来承伤侧那份无处安放。
- 订阅者（哪怕在询问上让出）完全结完之后，扣血才发生 —— 「造成伤害时」在「扣减体力」之前。

### D2. 麒麟弓的条件 = 渠道 + 目标

```lua
local cardEffect = damage.parent
if not cardEffect or cardEffect.kind ~= 'cardEffect' then return end
---@cast cardEffect CardEffect
if cardEffect.card.name ~= '杀' or cardEffect.target ~= damage.to then return end
```

- **渠道**：官方「渠道」定义 —— 因执行牌的效果造成的伤害，此牌就是渠道。我们的写法：伤害的 `parent` 就是发起它的那次 `CardEffect`；是【杀】才认（【决斗】【南蛮】【万箭】【闪电】的 parent 牌名不同，天然排除）。
- **对目标角色**：`cardEffect.target == damage.to` —— 现在恒真；官方「转移」的定义（先防止、再对他人造成同来源同渠道的新伤害）落地时，它就是「天香转移后不能对转移目标发动麒麟弓」那则裁定的落点（新伤害不是那张【杀】对自己目标的结算）。
- 不给 `useCard.user == owner` 加校验：订阅本来只在 `damage.from == owner` 时被叫醒，而今天【杀】的伤害 `from` 就是使用者 —— 与「不要过度防御」一致，真有「改来源不改使用者」的技能时再补。

### D3. 「可以」的表达 = 一个 askCard

- 候选只取坐骑牌（按分类 `坐骑`，不按区名 —— 特殊坐骑子区也覆盖）；一张都没有就不问（官方：无可弃之牌就发不了）。
- 弃哪张、弃不弃一次问完：不答 = 不发动（与无懈窗口「没人答 = 放弃」同口径）；答复不在选项里由内核拒收。
- 弃置落点 = `game:moveCard(牌, '弃牌')`（【过河拆桥】先例）。

### D4. 用例面

| 场景 | 期望 |
| --- | --- |
| 正例：目标有坐骑 | 问一次；询问时点还没扣血；候选只有坐骑（武器 / 防具不入选）；被弃的进弃牌堆、修正回落、其余装备不动；目标照常掉血 |
| 不答 | 不发动：坐骑还在、照常掉血 |
| 目标没坐骑 | 不问 |
| 【决斗】造成的伤害 | 不发动（渠道不是【杀】） |
| 旁人用【杀】 | 不发动（订阅只在来源身上） |
| 拆下武器后 | 不发动（被动停用、订阅随之撤） |

## Risks / Trade-offs

- 两个时机在每次伤害都会各发一次（哪怕没人订阅）—— 与既有每伤害必发 `'伤害-结束'` 同口径，成本是一次 `fire`。
- 天香类「转移伤害」落地后：若实现改成直接改 `damage.to`（而非造新伤害），D2 的目标校验保证不乱发动；若造新伤害（官方写法），新伤害的 parent 不是那张【杀】的 CardEffect，同样不乱发动。
