# Proposal

## Why

装备技能的第五张（按「一张牌一个功能点」推进）。【麒麟弓】只有定义（武器 / 攻击范围 5），「造成伤害时弃其坐骑」的官方效果未实现。

缺的不在牌侧、在一个**触发点**：伤害的时机只有 `'伤害-结束'`（≈「受到伤害后」，扣体力与濒死都处理完之后），没有「造成伤害时」（扣体力之前）——麒麟弓的发动时机正是后者（官方例子里直写「造成伤害时-2」）。

| 现状 | 影响 |
| --- | --- |
| 【麒麟弓】只有定义（武器 / 攻击范围 5） | 官方效果未实现 |
| 伤害只有 `'伤害-结束'` 一个时机（`@基础/伤害.lua`） | 「造成伤害时」类能力（麒麟弓，将来的古锭刀 / 寒冰剑）没有挂点 |
| 询问 / 弃置齐全（`game:askCard` + `game:moveCard`，【过河拆桥】先例） | 牌侧只差一个订阅 |

## What Changes

- `package/@基础/伤害.lua`：`Damage:settle()` 在扣体力**之前**发两个新时机 —— 全局 `'伤害-开始'`，再对来源发 `'伤害-来源-开始'`（没有来源就不发第二份）；`@基础/meta.lua` 补两条类型声明。
- `package/标准/卡牌/麒麟弓.lua`：『被动』里订 `owner:on('伤害-来源-开始')` —— 条件 = 这次伤害的渠道是本人使用的【杀】、且打的就是那张杀的目标；目标装备区里有坐骑牌才问本人（`game:askCard`，候选 = 目标的坐骑牌），弃掉（`game:moveCard` 进弃牌堆）。不答 = 不发动。
- 用例：`core.effect.damage` +2（新时机：扣血前发、全局先来源后、无来源只发全局那份）；`rule.equip` +6（正例 / 不答不发动 / 目标没坐骑不问 /【决斗】不发动 / 旁人用【杀】不发动 / 拆下武器不发动）。
- 文档：`sanguosha-rules` §7（伤害时机的说明）与 §9.11（麒麟弓移出「还没做」）；`progress.md`。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无对外契约变化（内容侧时机，与「判定 / 伤害-结束」同类）。探索期口径：本变更不写 `specs/`（`.openspec.yaml` 设 `skip_specs: true`）。

## Impact

- `package/@基础/伤害.lua`（新时机）、`package/@基础/meta.lua`（声明）
- `package/标准/卡牌/麒麟弓.lua`（技能）
- `server/test/core/effect/damage.lua`、`server/test/rule/equip.lua`（用例）
- 文档：`moe-kill-dev` 的 `references/progress.md`、`sanguosha-rules` 的 §7 / §9.11

## Non-goals

- 承伤侧的「受到伤害时」时机（`'伤害-目标-开始'`）—— 没有消费者，等真有天香类能力再开。
- 伤害的防止 / 修改（寒冰剑 / 古锭刀）—— 另批。
- 借刀杀人 + 武圣把武器当实体牌那类裁定（缺武将系统）；转移伤害（天香）只留对的口径（见 design），传导 / 转移系统本身不在本批。
- 其余装备技能。
