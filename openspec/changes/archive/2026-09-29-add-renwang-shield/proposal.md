# Proposal

## Why

装备技能第二张。**挑【仁王盾】的理由**（与其余候选比过）：「黑色的【杀】对你无效」**零新机制**——`'效果-能否生效'`（逐目标拦、返回值即原因）+『被动』（进槽启用 / 离槽停用）+ 牌面花色（`card.suit`）全都已就绪；它还给「防具技能」开头（【八卦阵】才需要「替换 / 追加一次响应」的新能力），并顺带为【青釭剑】的「无视防具」铺路（后者可用**被动压制**表达 —— 记在 Non-goals，不在本批做）。

| 现状 | 影响 |
| --- | --- |
| 【仁王盾】技能空（只有定义与分类） | 「黑色【杀】对你无效」未实现 |
| 接缝已备（见上） | 预计单文件一个『被动』订阅 + 一组用例 |

## What Changes

- `package/标准/卡牌/仁王盾.lua` 挂技能：『被动』订阅 `'效果-能否生效'` —— 这次生效是【杀】、目标是装备主、且这张【杀】是**黑色**（黑桃 / 梅花） ⇒ 返回原因（这次生效被阻止 —— 即「无效」）。
- 用例（`rule/equip`）：黑杀无效（不掉血、**连【闪】都不问**）/ 红杀照常（要闪、没闪掉血）/ 拆下后黑杀恢复 / 打没盾的人不受影响。
- 文档：`sanguosha-rules` §9.11（仁王盾移出「还没做」）、`progress.md`。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无新增对外契约（内容侧技能；接缝是现成的）。探索期口径：本变更不写 `specs/`（`.openspec.yaml` 设 `skip_specs: true`）。

## Impact

- `package/标准/卡牌/仁王盾.lua`（技能）
- `server/test/rule/equip.lua`（用例一组）
- 文档：`moe-kill-dev` 的 `references/progress.md`、`sanguosha-rules` 的 §9.11

## Non-goals

- 【八卦阵】（要「替换 / 追加一次响应」的新能力）与其余装备技能（各是一个功能点）。
- 【青釭剑】的「无视防具」——将来做时用**被动压制**表达（对目标的防具牌 `disablePassive()` / 恢复），本批不做。
