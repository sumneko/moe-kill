# Design

## Context

- 官方：「**锁定技**，黑色的【杀】对你**无效**。」
- 现成的三件接缝：`'效果-能否生效'`（每个 `CardEffect` 结算前问一次，**返回非 nil 即阻止**，返回值就是原因 —— 【无懈可击】先例）；『被动』（装备进槽启用 / 离槽停用，回调返回 disposer）；`card.suit`（牌面花色，标准牌表用的中文：黑桃 / 红桃 / 梅花 / 方片）。
- 【杀】的 `'生效'` 就是「要【闪】，没有就伤害」——**阻止**这次生效 = **整段不跑** ⇒ **不**要闪、**不**伤害。

## Goals / Non-Goals

**Goals:**

- 仁王盾的技能：锁定技（无条件）+ 只拦「对装备主的【杀】」+ 只拦黑色。
- 用例覆盖：黑杀无效连闪都不问 / 红杀照常 / 拆下恢复 / 打别人不受影响。

**Non-Goals:**

- 【八卦阵】与其余装备技能。
- 【青釭剑】「无视防具」（将来用被动压制表达）。

## Decisions

### D1. 技能形状 =『被动』订阅 `'效果-能否生效'`

```lua
: on('被动', function (card, zone)
    local owner = assert(zone.owner)
    return game:on('效果-能否生效', function (effect)
        if effect.kind ~= 'cardEffect' then
            return
        end
        ---@cast effect CardEffect
        if effect.card.name ~= '杀' or effect.target ~= owner then
            return
        end
        if effect.card.suit == '黑桃' or effect.card.suit == '梅花' then
            return '仁王盾'
        end
    end)
end)
```

- 「无效」= **阻止这次生效**（`.err` = 原因、不算失败）—— 逐目标天然成立（【杀】对每个目标各一个 `CardEffect`，这里只拦装备主那个）。
- 返回值写牌名（「仁王盾」），与【无懈可击】return `'无懈可击'` 同一口径。

### D2. 「锁定技」= 无条件

没有「你可以」，不做询问、不做开关；装上就有、离槽即无（由被动生命周期负责）。

### D3. 黑色 = 黑桃 / 梅花

花色的**值**是内容侧写的字面量（`card.suit`，内核只存不解释）；标准包内部直呼「黑桃 / 梅花」两值（内容侧写自己的牌允许；机制侧不建按名分支）。

### D4. 用例面

| 场景 | 期望 |
| --- | --- |
| 黑色【杀】打装备者 | 不掉血；**连【闪】都不问**（整段生效没跑） |
| 红色【杀】打装备者 | 照常 —— 要【闪】，没闪掉 1 点 |
| 装备者拆下盾后再吃黑杀 | 照常掉血（被动停用） |
| 黑色【杀】打没盾的人 | 不受影响 |

用例里用 `game:createCard('杀', '黑桃', …)` 造指定花色的【杀】（不受牌堆洗牌影响）。

## Risks / Trade-offs

- **[「无效」的位置]** 拦住 `CardEffect` ⇒ **响应窗口不发生**（官方「无效」的常见解释：不必闪、直接无事）；若将来口径改成「先闪再无效」，只需把拦截点挪到伤害前，用例跟着改。
- **[回退]** 单文件、单钩子：撤掉『被动』订阅即回原状（机制对默认牌零影响）。
