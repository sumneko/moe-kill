# Spec Delta

## MODIFIED Requirements

### Requirement: 有序取牌与可复现洗牌

牌区 SHALL 可以声明"有序"能力：具备该能力的牌区按固定顺序取顶，并可洗牌。洗牌消费的随机源 SHALL 来自「创建时绑定」或「调用时传入」之一（至少一种）：在相同随机源状态下，同一内容的牌区 MUST 洗出相同顺序；两者都没有时 MUST 以明确失败暴露。不具备该能力的牌区被要求取顶或洗牌时 MUST 以明确失败暴露。

#### Scenario: 相同随机源洗出相同顺序

- **WHEN** 用两个状态相同的随机源分别洗两份内容相同的抽牌堆
- **THEN** 两次得到的顺序完全一致

#### Scenario: 按顺序取牌

- **WHEN** 依次从有序牌区取牌
- **THEN** 取出的顺序与洗牌后的顺序一致

#### Scenario: 绑定过随机源的牌区洗牌可以省略参数

- **WHEN** 一个创建时绑定了随机源的有序牌区被要求洗牌，且不传随机源
- **THEN** 用绑定的那个随机源洗牌，顺序与直接用同一随机源洗的结果一致

#### Scenario: 既没绑定又没传参时明确失败

- **WHEN** 一个既没有绑定随机源、调用时也没传随机源的有序牌区被要求洗牌
- **THEN** 该操作以明确失败暴露，而不是静默不洗或报出别的原因

#### Scenario: 无序牌区不支持取顶

- **WHEN** 对不具备有序能力的牌区请求取顶或洗牌
- **THEN** 该操作以明确失败暴露
