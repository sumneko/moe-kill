# Spec Delta

## Purpose

定义内核提供的随机源：可实例化、可注入且结果确定，使依赖随机性的操作（如洗牌）在测试中可复现，并让多个房间互不干扰。

## ADDED Requirements

### Requirement: 可实例化且可注入

随机源 SHALL 可以按给定种子创建多个实例，并 SHALL 可以被注入到需要随机性的操作中。内核 MUST NOT 依赖全局随机状态（例如全局 `math.random` 的共享状态）。

#### Scenario: 注入到洗牌

- **WHEN** 把随机源实例传给抽牌堆的洗牌操作
- **THEN** 洗牌使用该实例产生顺序，而不是内核自己的全局随机状态

### Requirement: 确定性

在相同种子的两个随机源实例上，按相同顺序请求相同次数的随机值 MUST 得到相同结果。

#### Scenario: 同种子同序列

- **WHEN** 用相同种子创建两个随机源，并依次请求同一批随机值
- **THEN** 两次请求得到的序列完全一致

#### Scenario: 不同种子不同序列

- **WHEN** 用不同种子创建随机源并请求同一批随机值
- **THEN** 得到的序列不同

### Requirement: 实例间互不干扰

多个随机源实例 SHALL 相互独立：在一个实例上消耗随机值 MUST NOT 影响另一个实例后续产生的结果。

#### Scenario: 消耗其中一个不影响另一个

- **WHEN** 先用实例 A 请求若干随机值，再交替使用 A 与 B
- **THEN** B 产生的序列与它单独使用时一致
