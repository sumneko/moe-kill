# Spec Delta

## Purpose

让规则集能按**时机名**注册回调、由装配与流程代码在恰当时机触发：时机名不预设（规则集自由使用字符串），回调按**注册顺序**执行且返回可撤销的登记，注册随规则集清空重载一起清空；对状态的改动（如设置身份、改体力上限）由后注册的回调自然覆盖，回调报错不打断其余回调。

## ADDED Requirements

### Requirement: 加载期时机注册

规则集 SHALL 能在加载过程中按**时机名**注册回调（`rule:on('游戏开始', function (ctx) ... end)`），时机名 MUST NOT 被预设或校验（任意字符串）。注册 MUST 返回 disposer，调用它精确撤销这一次注册。同一个时机名下的回调 SHALL 按**注册顺序**依次执行。注册 MUST 与规则表同生命周期：清空重载后，上一轮注册的回调 MUST NOT 再被触发。

#### Scenario: 注册后能被触发

- **WHEN** 规则集文件在加载期对某个时机名注册回调，随后触发该时机
- **THEN** 回调被执行，并收到触发时传入的上下文

#### Scenario: 按注册顺序执行

- **WHEN** 同一时机名下先后注册多个回调并触发
- **THEN** 它们按注册顺序依次执行（后注册的后执行），因此后注册者对状态的改动覆盖先前的

#### Scenario: 撤销一次注册

- **WHEN** 对一次注册调用它返回的 disposer，再触发该时机
- **THEN** 该回调不再被执行，其余回调不受影响

#### Scenario: 清空重载后不再触发旧回调

- **WHEN** 加载一轮规则集（含时机注册）后清空重载，且新一轮不再注册该回调，然后触发该时机
- **THEN** 旧回调不被执行

#### Scenario: 加载之外不能注册

- **WHEN** 在没有加载上下文时调用注册接口
- **THEN** 以错误结束

### Requirement: 按名触发与错误隔离

装配 / 流程代码与无头测试 SHALL 能按时机名触发（`rule:fire('游戏开始', ctx)`），并传入一个上下文（约定为只读，改状态靠调用接口而非改上下文）。触发某个时机名时，未注册任何回调 SHALL 是合法的空操作。单个回调报错 MUST NOT 打断其余回调，也 MUST NOT 让触发本身失败；错误 SHALL 走统一错误报告（`log.error`）。

#### Scenario: 未注册的时机名触发是空操作

- **WHEN** 触发一个没有任何回调的时机名
- **THEN** 不报错，什么都不发生

#### Scenario: 一个回调报错不影响其余

- **WHEN** 同一时机名下三个回调，中间那个抛错，然后触发
- **THEN** 第一个与第三个仍然执行，错误被记录

#### Scenario: 触发时传入上下文

- **WHEN** 触发时机并传入上下文表
- **THEN** 每个回调都能读到该上下文
