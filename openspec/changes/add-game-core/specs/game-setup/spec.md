# Spec Delta

## Purpose

定义开局装配的可观察结果：按人数分配身份、洗牌、发牌，使"开局是否正确"能够被无头测试断言，且不依赖任何会话或协议层。

## ADDED Requirements

### Requirement: 身份分配

开局装配 SHALL 按人数从身份配置表分配身份，其中主公 MUST 唯一，其余身份的数量 MUST 与配置表一致；在相同随机源状态下，装配结果 MUST 可复现。

#### Scenario: 四人局身份构成

- **WHEN** 对四名玩家执行身份分配
- **THEN** 身份构成为一名主公、一名忠臣、一名反贼、一名内奸

#### Scenario: 相同随机源复现

- **WHEN** 用两个相同的随机源状态分别执行两次装配
- **THEN** 两次的身份分配结果一致

### Requirement: 洗牌与发牌

洗牌 SHALL 使用可注入的随机源；发牌后每名玩家的起手牌数 MUST 一致，且牌 MUST 守恒（已发出的牌数 + 抽牌堆剩余数 = 装配前的总数）。

#### Scenario: 起手牌数一致

- **WHEN** 装配一局并完成发牌
- **THEN** 每名玩家的手牌数量相同且等于配置的起手牌数

#### Scenario: 牌守恒

- **WHEN** 对比装配前后的牌数与已发出的牌数
- **THEN** 已发出的牌与抽牌堆剩余之和等于装配前的总数

### Requirement: 装配默认口径

装配 SHALL 采用标准版默认口径且这些默认值 MUST 可配置：主公体力上限在主公确定后 +1，先手角色为主公。

#### Scenario: 主公体力上限与先手

- **WHEN** 完成一局装配
- **THEN** 主公的体力上限比其它角色高 1，且当前回合角色为主公
