# Spec Delta

## Purpose

定义一局游戏里玩家、桌子、房间的数据与查询行为，使局面可以被无头测试直接构造、驱动与断言，而不需要任何会话或协议层。

## ADDED Requirements

### Requirement: 玩家状态与区域

玩家 SHALL 具备身份、体力、体力上限、存活状态，以及手牌区、装备区、判定区三个区域；体力变化与区域操作的结果 MUST 可查询。体力 MUST NOT 超过体力上限，也 MUST NOT 低于 0。

#### Scenario: 受伤与回复受上限约束

- **WHEN** 对一个满体力玩家造成伤害，随后回复体力
- **THEN** 体力按伤害量减少且不低于 0，回复后不超过体力上限

#### Scenario: 区域操作可查询

- **WHEN** 往玩家手牌区放入若干牌、从手牌区取出一张、把一张牌移入装备区与判定区
- **THEN** 各区域的内容与数量查询结果与操作一致

### Requirement: 桌子座位与行动顺序

桌子 SHALL 作为座位与行动顺序的载体：支持玩家入座、按行动顺序遍历存活玩家、查询某个玩家的座位序号与相邻玩家。座位与行动顺序 MUST 可查询且不依赖任何 IO。

#### Scenario: 按行动顺序遍历

- **WHEN** 四个玩家依次入座后请求按行动顺序遍历
- **THEN** 得到的顺序与入座顺序一致，且可从一个玩家查到其下一个座位

#### Scenario: 跳过已阵亡玩家

- **WHEN** 行动顺序中的某个玩家已阵亡后再次遍历行动顺序
- **THEN** 该玩家不出现在行动顺序中

### Requirement: 座位距离

系统 SHALL 提供座位距离求值：沿桌面两个方向取较小值，最小为 1；装备或技能带来的修正 SHALL 参与求值，且修正后距离仍最小为 1。距离 MUST 是求值结果而不是缓存字段。

#### Scenario: 基础距离

- **WHEN** 在四个座位的桌子上计算 1 号座与 2 号座、1 号座与 3 号座的距离
- **THEN** 分别为 1 与 2

#### Scenario: 装备修正与下限

- **WHEN** 目标装备了使距离 +1 的马、或自己装备了使距离 -1 的马
- **THEN** 距离按修正变化，且任何情况下不小于 1

### Requirement: 房间装配与隔离

房间 SHALL 作为一局的装配根：支持加入玩家、查询玩家集合与当前局面，并持有该局的桌面与各牌堆。不同房间之间的状态 MUST 互不影响。

#### Scenario: 装配并查询

- **WHEN** 创建一个房间并加入两个玩家
- **THEN** 查询到的玩家数量与身份与加入时一致

#### Scenario: 两个房间互不影响

- **WHEN** 同时创建两个房间并分别操作
- **THEN** 任一房间的玩家、座位与牌堆状态都不受另一个房间影响
