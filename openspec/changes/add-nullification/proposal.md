# Proposal

## Why

普通锦囊只剩最后一张【无懈可击】。它不只是"再补一张牌"：官方给它的插入点是**使用结算中的「生效前」**（逐目标），而我们现在唯一的「响应」——【闪】——是写在【杀】自己的 `'生效'` 钩子里的。也就是说，**「与单张牌无关、对任意锦囊生效的抵消」这条通道还没有实例**；做它是第一件，后面【八卦阵】【仁王盾】那类"同一窗口里的窗口响应"都照它的形状走。

## What Changes

- **内核新增「对一张牌使用」这一支**（与「对角色使用」并列，不混在一个目标字段里）：
  - 新效果类 `UseCardToCard`（一次使用、目标是一张牌）与 `CardEffectToCard`（对那张牌的一次生效），与 `UseCard` / `CardEffect` 对称；沿用同一套「结算前 / 收尾」时机与「记一次使用」。
  - 新定义项（也是新的固定钩子）**`'对卡牌生效'`**：**声明它就代表这张牌能被「对一张牌使用」**；`canUseToCard` 的合法性就落在这条声明上，**目标牌由发起方给定**（这类目标只存在于发起它的那次结算里，内容侧枚举不出来）。
  - 新入口：`game:useCardToCard(使用者, 牌, 目标牌)`、`game:canUseToCard(使用者, 牌, 目标牌?)`、`game:askUseCardToCard(被问者, 缘由, { name = …, target = 目标牌 })`（选项逐张跑 `canUseToCard`，答复只要给牌）。
  - `'卡牌-能否使用'` 的载荷补一条 `target?`（对牌使用时的目标牌）；`'结算前'` / `'结算后'` 与 `'卡牌-结算前'` / `'卡牌-结算后'` 的载荷放宽成 `UseCard|UseCardToCard`。
- **【无懈可击】自己提供无懈响应**（`package/标准/卡牌/无懈可击.lua`）：这张牌的文件里声明 `'对卡牌生效'`（= 它只能「对一张牌使用」⇒ 没有 `'获取目标'`，出牌阶段根本不会提供它），并订阅内核**现成的** `'效果-即将生效'` 时机 —— 只认「**锦囊牌对某个角色的一次生效**」（`effect.kind == 'cardEffect'` + `effect.card:isKind('锦囊')`），在那里按行动顺序问一圈**要不要使用【无懈可击】抵消这张牌**（`askUseCardToCard` + `useCardToCard`），净结果是被抵消就 `effect:remove()`（此时我们正跑在这次生效自己的执行体里 ⇒ 取消才有效），该目标不生效、牌照常进弃牌堆。**规则随牌走**：没装这张牌的规则集不会开这个窗口。
- **分层循环**：用了【无懈可击】的那一层，自身再走一层（可以被另一张【无懈可击】抵消）。层数为奇数 ⇒ 原锦囊被抵消；偶数 ⇒ 原锦囊照常生效（官方是"嵌套"：第二张无懈的对象是上一张无懈，不是原锦囊 —— 同一张锦囊不会被连续无懈两次）。每层按**行动顺序**问一圈（起点 = 顺序锚点，每人在该层最多答一次）。
- **逐目标**（官方口径）：多目标锦囊可以对**某一个角色**单独抵消，其余目标照常结算 —— 落点就是 `'效果-即将生效'` 本来就逐目标触发；答复方要知道这次是冲谁来的，看这次询问的父效果（`ask.parent` 就是那次生效）。
- 牌表里那 4 张【无懈可击】**已经在了，不用改**。
- **本批不做**：延时锦囊的无懈窗口（要等判定区与延时锦囊那批；判定动作本身已落地）、"谁能响应"的技能干预（如【看破】）、询问超时（等 `timeout` 那批）、把【闪】也迁到「生效前」。

## Capabilities

### New Capabilities

- 无

### Modified Capabilities

- `core-play`：新增「对一张牌使用」这一支（`UseCardToCard` / `CardEffectToCard` / `useCardToCard` / `canUseToCard` / `askUseCardToCard`）与牌的钩子 `'对卡牌生效'` —— 这是**内容侧可见的契约变化**（第三方包要写【无懈可击】那类牌就得用它），所以本批**照常写 specs 增量**、不设 `skip_specs`。

## Impact

- **内核（新增 / 改动）**：`server/core/effect/use-card-to-card.lua`（新）、`server/core/effect/ask-use-card-to-card.lua`（新）、`server/core/effect/init.lua`、`server/core/game.lua`（抽出一条两入口共用的「牌本身能不能用」校验 + 三个新入口）、`server/core/loader/env-meta.lua`（新钩子、载荷类型放宽、`'卡牌-能否使用'` 加 `target?`）。
- **内容（新增）**：`package/标准/卡牌/无懈可击.lua`（牌定义 + 它自己的响应循环）。
- **用例**：`server/test/rule/trick.lua`（无懈 7 条：没人用 / 一层抵消 / 两层互相抵消 / 多目标只抵消一个 / 非锦囊不问 / 主动用不出去 / 答复不在选项里）+ 既有用例里几条询问脚本加「忽略无懈询问」的护栏。
- **文档**：`sanguosha-rules` §9.10（锦囊一节补【无懈可击】的口径与落点：官方是**使用**、逐目标、嵌套；我们落在 `'效果-即将生效'` + `remove()`，且取消只能由那次生效自己的执行体发起；【闪】是"打出"响应、与它位置不同）、`moe-kill-dev/references/architecture.md` §12（「效果-即将生效」= 官方的「生效前」；新增「对牌使用」这一支）、`references/progress.md`。
