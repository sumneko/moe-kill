# auto-cast

## Why

`Cast`（上一个变更）落了「技能 / 装备发动的归因」，但有两张牌内容侧包不了：

- **【丈八蛇矛】**：真正的发动在内核 —— 内容侧只写 `addViewAs('杀', card, {…})` 声明，`'发动'` 钩子省略（默认成立），**内容侧没有代码点**。
- **【八卦阵】**：发动写在 `ViewAs` 的 `'发动'` 钩子里，但那次判定是内核跑钩子时发生的。

用户 2026-10-01 定：**让 `ViewAs` 自己包** —— 视为成立时，自动对它的 `source`（关联来源：装备的那张牌 / 技能实例）执行一次 `cast`。

## What Changes

- **`ViewAs:tryProduce`**：有关联来源就把「表态 + 收素材 + 造牌」整段包成一次 `source:cast(…)`；没有来源（测试与将来玩家自挂的声明）照旧不包。拆出 `---@private` 的 `launch(ask)`。
- **【八卦阵】**：撤掉上一批手写的 `card:cast`（改由内核自动包）。
- **【仁王盾】**：阻止时补一次空跑 `card:cast(function () end)`（用户点名：这次阻止归到盾的名下）—— 它没有「做事」的一段，只能空跑占住发动点。
- 用例 +1（`core.view-as`：`'发动'` 钩子里起的结算挂在关联来源名下）。

## Non-goals

- 不改 `ViewAs.source` 的用途 —— 只把类型从 `any` 收窄成 `Card|Skill`（用户 2026-10-01 要求）。
- 不给「空跑 cast」加通知（现在谁都看不见它；要观察得另加一条时机，将来再说）。
- 【方天画戟】/【诸葛连弩】仍不包（一个只改数量、一个装上就生效，都没有「发动后做事」那一段）。
