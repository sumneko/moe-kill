# Spec Delta

## MODIFIED Requirements

### Requirement: 重载后已存在的实例立即使用新代码

重载 SHALL 复用同名类的既有类表（合并语义），使得重载之后**已经存在的实例**立即使用新代码；MUST NOT 要求调用方重建实例，也 MUST NOT 让老实例继续执行被替换掉的旧代码。**局**（`moe.game`）同样适用：局与装载器本身都可重载，重载后已存在的局 SHALL 继续可用（规则表、规则数值、时机注册与属性系统照旧，新代码立即生效）。

#### Scenario: 老实例调用到新方法

- **WHEN** 创建一个实例，修改其类所在模块的方法体并触发重载，再用同一个实例调用该方法
- **THEN** 执行的是重载后的新方法体

#### Scenario: 老实例的状态与类型不变

- **WHEN** 对一个重载前创建的实例，在重载后读取它的自有字段、判断它的类型或标识
- **THEN** 结果与重载前一致（对象本身既没被重建也未被判为无效）

#### Scenario: 规则实例跨重载照常可用

- **WHEN** 建好一局（已装一份清单），随后触发热重载，再从这一局查询条目与规则数值
- **THEN** 查询结果与重载前一致，局没有被丢弃，也不需要重建
