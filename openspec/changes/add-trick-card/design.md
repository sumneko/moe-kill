# Design

## Context

- **用牌这条链已经齐了**（`server/core/game.lua` 的 `useCard`）：`canUse` 校验（内建条目 + 内容侧 `'卡牌-能否使用'`）→ 内核记一次次数 → 从使用者名下牌区取牌 → **`'卡牌-结算前'`**（基础规则放进 `处理`）→ **按行动顺序对每个目标各跑一次 `'生效'`** → **`'卡牌-结算后'`**（基础规则送进 `弃牌`）。
- **基本牌怎么写的**：`package/@基础/基本牌.lua` 是公共模板（`Card '基本牌' : kind '基本' : zone '手牌'`，**不在牌表里、不会被造出来**），`杀` / `闪` / `桃` 都 `: extends '基本牌'` 再加自己的 `'获取目标'` / `'生效'`。
- **锦囊的位置**：牌表里 10 种即时锦囊共 31 张，**一张都没实现**；`kind` 的覆盖口径（2026-09-23）就是为「锦囊 = 一张牌同时属于两类」准备的。
- **还没做的能力**：无懈可击（需要嵌套询问窗口 `askSkill`）、选别人的牌（过河拆桥 / 顺手牵羊 / 借刀杀人）、多轮交替响应（决斗）、判定区（延时锦囊）。

## Goals / Non-Goals

**Goals:**

- 第一张**普通（非延时）锦囊**能真的用出去：分类对、目标对、生效对、用过的牌按既有路径进 `处理` → `弃牌`。
- 把「锦囊」的写法**定下来**（模板 + 单张牌的写法），后面 9 张照抄。
- **内核一行不改** —— 这说明前一阶段的内核能力（多目标、逐目标生效、筛选、去向）已经够用。

**Non-Goals:**

- 无懈可击（见 D4：它的插入点与单张锦囊无关）。
- 其它 9 种即时锦囊（各自另开：有的要选牌、有的要交替响应）。
- 延时锦囊与判定区。
- 锦囊的可见性 / 前端表现（牌面早已有，表现留给会话批次）。

## Decisions

### D1 先做【无中生有】，并抽一个「锦囊牌」模板

```lua
-- package/@基础/锦囊牌.lua（模板：不在牌表里、不会被造出来）
Card '锦囊牌'
    : kind { '锦囊', '非延时锦囊' }
    : zone '手牌'
```

```lua
-- package/标准/卡牌/无中生有.lua
-- 【无中生有】（标准版）
-- 出牌阶段，对自己使用。摸两张牌。

Card '无中生有'
    : extends '锦囊牌'
    : on('获取目标', function (ctx)
        return { ctx.user }
    end)
    : on('生效', function (ctx)
        game:draw(ctx.target, 2)
    end)
```

- **为什么抽模板**：`{ '锦囊', '非延时锦囊' }` + `zone '手牌'` 是 10 张即时锦囊的公共部分（与基本牌模板同一个理由），一处改全对。
- **延时锦囊将来怎么接**：`: extends '锦囊牌' : kind { '锦囊', '延时锦囊' }` —— 分类**覆盖**成延时那一支（这正是 2026-09-23 改口径的用处）；置入判定区是「生效」里的事，将来另开。

### D2 目标就是使用者自己

- 官方描述是「对自己使用」⇒ `'获取目标'` 返回 `{ ctx.user }`；效果走**逐目标生效**（只有一个目标 ⇒ 跑一次），`'生效'` 里 `game:draw(ctx.target, 2)`。
- 不给「目标为空表」的例外：`canUse` 要求目标非空且是合法目标的子集，所以用的时候给 `{ 自己 }`（出牌阶段筛选项时内核会把它拼好 —— `ask.options` 里带 `targets = { 自己 }`）。
- **顺手的好处**：这张牌把「单目标 + 摸牌」跑通，摸牌本身已经能处理「牌堆不够就洗回」与「两堆都空 ⇒ 平局」（都是既有能力）。

### D3 不声明 `limit`

锦囊按官方每回合不限次（【无中生有】也不例外）⇒ 不写 `: limit(...)`，`getLimit` 的兜底 1000 就是「事实上不限」。

### D4 无懈可击将来插在哪（本批不做，但先把话说清）

无懈可击是「当一张锦囊牌**生效前**，任何角色可以打出它来抵消」⇒ 插入点是**内核发 `'卡牌-结算前'` 的那一刻**（基础规则里按 `isKind('锦囊')` 判断，再问一圈有没有人打无懈，被打出就 `useCard` 的效果 `reject` 掉，整张牌作废）。**这与单张锦囊自己的定义无关**，所以现在做【无中生有】不会给它挖坑；将来加无懈时改的是基础规则 + 内核的询问能力（`askSkill` / 嵌套窗口），【无中生有】一行不改。

### D5 验收方式

用例（`server/test/rule/trick.lua`）钉三件事：

1. **用出去就摸两张**：手牌净 +1（那张锦囊进了 `处理` → `弃牌`，手牌 +2）、抽牌堆 -2、`弃牌` 里有它。
2. **只能以自己为目标**：`canUse(user, card, { 别人 })` 明确失败；`canUse(user, card, { user })` 通过。
3. **分类**：`isKind('锦囊')` 与 `isKind('非延时锦囊')` 都为真（内容侧真的用了列表口径）。
