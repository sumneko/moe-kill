# 变更：最后一名标准武将【诸葛亮】（观星 / 空城）

## 需求

落地标准包最后一名武将**诸葛亮**（蜀 · 男 · 3），顺带补两处内核能力：

1. **【观星】**：准备阶段开始时，你可以观看牌堆顶的 X 张牌，然后将任意数量的牌置于牌堆顶，将其余的牌置于牌堆底。（X 为存活角色数且至多为 5）
2. **【空城】**：锁定技，若你没有手牌，你不能被选择为【杀】或【决斗】的目标。
3. **内核能力：有序牌区的「置于区顶 / 区底」** —— 现在 `Zone` 只有 `accept`（追加 = 区**底**），观星必须能把一批牌**按序放回区顶**。

## 为什么

- **观星是缺口表里最后一栏**（`progress.md` §3「置入牌堆顶 / 底」）：`Zone` 只有 `accept`，位置 / 插入语义整个不存在；【遗计】改用「牌进临时区、分完不剩牌」之后绕开了它，现在只剩观星要。
- **牌堆不足本批不动**（2026-10-09 逐行核过后撤回）：底本 `Ch1/Section2.md:89` 的三支 —— ①（牌堆 + 弃牌）＜ X ⇒ 平局、② 0 ＜ 牌堆 ＜ X ⇒ 弃牌洗混后置于牌堆底、③ 牌堆 = 0 ⇒ 先洗牌 —— **现状都已吻合**：不足回调只在「已经取空」那一刻触发（`#self.cards == 0`），那时顶上原有的牌早已被取走 ⇒ 搬入弃牌 + 整堆 `shuffle()` 洗的正是弃牌堆的全部，等价于 ②。唯一残留是**执行顺序**：「连弃牌都不够」时底本先判平局、不取牌，现状取到取不动再判（已取走的那几张留在结果里）—— 局面已终局、实际玩不出差别，记进文档当**已知偏离**。
- **【空城】不需要新能力**：`'卡牌-目标-能否指定'` 现成可用（【谦逊】同款；`game:getLegalTargets` 逐候选问一句，返回非空即剔出候选）。

## 做什么

1. **内核**：`OrderedZone:placeTop(牌表)` / `placeBottom(牌表)`（收有序牌表，第一张更靠区顶；顺序约定只写在这一处）。
2. **内容 `package/标准/武将/诸葛亮.lua`**（新）：`Hero '诸葛亮'` + `Skill '观星'`（准备阶段开始 + 观看 + 放回；**分配暂由服务器给定**，见「不做什么」）+ `Skill '空城'`（`'卡牌-目标-能否指定'`）。
3. **用例**：内核（`placeTop` / `placeBottom`：顺序、已在区内的牌、空列表）+ 观星（观看、放回、X 的上限、不发动）+ 空城（有手牌可指定 / 没手牌不可指定 / 只挡【杀】与【决斗】/ 视为的【杀】也算）。
4. **文档**：`architecture.md`（`OrderedZone` 的位置能力 + 「1 = 顶」的顺序约定 + 不足口径的**已知偏离**）、`sanguosha-rules` §9.x 诸葛亮 + 缺口表、`progress.md`（基线 + 本批条目）。

## 不做什么

- **不做「排列」询问类**（用户 2026-10-09 定：形状先想一想）⇒ 观星的「哪些放顶、什么顺序」本批**由服务器暂定**（一个显式标注的占位分配），等那个询问类到位再换成玩家的答复。
- **不动牌堆不足口径**（2026-10-09 用户核对后定）：现状已与底本一致，唯一残留的执行顺序差异（「连弃牌都不够」那一支）记文档、不改内核 —— 详见「为什么」那条。
- **不给「强制加目标」加校验**：`useCard:addTarget` 是裸追加、不过 `'卡牌-目标-能否指定'`（底本 `Ch2/S5:298` 的【求援】例子要求空城挡得住）。本批只在文档记下口径：**加目标要走 `getLegalTargets` 筛过的名单**（【流离】就是这么写的）；将来真出现绕过它的技能再谈。
- **不动判定路径**：X = 1 ⇒ 只有「牌堆 = 0」两支出得来，现行为已与底本一致。
- **不动 `openspec/specs/`**（冻结期）。
