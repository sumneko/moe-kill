# Proposal

## Why

结算期间总有一批牌要「先放在一边」：

- 【五谷丰登】亮出的牌（不属于任何人的牌区，逐人取走）；
- 判定翻出的牌（在 `'判定-后'` 之前不属于任何区）；
- 打出 / 使用的牌（结算期间离开手牌，结束后进弃牌堆）。

现在两种做法都不好：

1. **全局 `处理` 区**（`package/@基础/牌堆.lua` 建，`使用.lua` / `打出.lua` 一进一出）：单张一进一出够用，但**一批牌要边取边走**时不行 —— 牌全挤在一个区里，分不出「哪几张是这次结算的」。
2. **效果上的标签袋记一个数组**（【五谷丰登】现在的 `setTag('剩余', ...)` + `table.without`）：账本是**平行**维护的，与真实位置会漂移（忘了删 ⇒ 收尾时把已经不在手上的牌再送一次弃牌）；嵌套结算（将来的无懈可击、判定）下两批牌混在一起。

而且**收尾**没有统一的地方：牌什么时候算「结算完了、该走了」，得每个内容文件自己数着（五谷丰登写在 `'结算后'`、打出写在 `'卡牌-答复后'`）。

用户 2026-09-23 定：**每个效果自带一块临时处理区**（效仿 `Zone` 的通用容器，懒建），效果结束自动收尾。

## What Changes

- **内核：`Effect` 多一块临时处理区** —— `getTempZone()` 按需 `moe.zone.create()`（懒建）；`tempZone` 字段可直接读（没建过就是空）。它**不进公共区表**（不是 `game:createZone`）、**没有区名**，随效果生命周期存在。
- **内核：收尾时机 `'效果-收尾'`** —— 这次效果结完时触发（正常 / 不成立 / 取消 / 超时都算），上下文 = 效果自己，**在所有子效果结完之后**。内核**不挪牌**：往哪去由规则决定。
- **内核：`Effect` 类搬到 `server/core/effect/effect.lua`** —— `effect/init.lua` 只做「加载子文件」（与 `server/core/init.lua` 同形）。
- **内容侧：`package/@基础/收尾.lua`**（新）—— 订阅 `'效果-收尾'`，把临时区里剩下的牌送 `弃牌`（一处说了算，各内容文件都不用再操心）。
- **内容侧：判定 / 使用 / 打出** —— 翻出的判定牌、用过的牌、打出的牌都进各自的临时区（打出的牌归**发起那次结算**，见 design D7）。
- **内容侧：【五谷丰登】** 改用它：亮出的牌进临时区、逐人取走、剩余由收尾自动送弃牌（`'结算后'` 钩子与 `table.without` 都删掉）。
- **用例**：内核（懒建 / 收尾只触发一次 / 不成立也收尾 / 子效果结完才收尾 / 不在公共区表）+ 规则（五谷丰登既有 4 条不走样）。
- **批二（同一变更内一并完成）**：判定 / 使用 / 打出的牌也进临时区，`处理` 公共区废弃（`@基础/牌堆.lua` 不再建它）。
- **明确不做**：临时区的前端表现（表现留给会话批次）。
