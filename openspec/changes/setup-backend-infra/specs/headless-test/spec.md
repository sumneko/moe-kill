# Spec Delta

## Purpose

定义在无界面、无前端、无外部客户端的环境下运行测试的入口与过滤行为，作为本项目后续所有验收手段（含「无前端跑完整对局」）的基础。

## ADDED Requirements

### Requirement: 测试模式入口

进程 SHALL 支持以命令行参数进入测试模式；测试模式下 MUST NOT 进入服务模式（不启动任何对外监听、不等待外部客户端）；退出码 `0` MUST 表示全部测试通过，非 `0` MUST 表示存在失败。

#### Scenario: 进入测试模式

- **WHEN** 以测试参数启动进程
- **THEN** 进程执行测试并输出测试结果摘要，不建立任何对外监听

#### Scenario: 全部通过时的退出码

- **WHEN** 所有测试用例通过
- **THEN** 进程以退出码 `0` 结束

#### Scenario: 存在失败时的退出码

- **WHEN** 至少一个测试用例失败
- **THEN** 进程以非 `0` 退出码结束

### Requirement: 测试过滤

测试模式 SHALL 支持按目标名只运行匹配的测试模块，且 MUST 支持按子路径逐层收窄（如从某大类收窄到其下某个子模块）；当过滤器没有匹配到任何测试模块时，进程 MUST 明确报错而不是静默"全部通过"。

#### Scenario: 只运行指定模块

- **WHEN** 以某个子模块名作为过滤目标
- **THEN** 只执行该子模块及其下层模块的测试，其它模块不执行

#### Scenario: 过滤器无匹配

- **WHEN** 使用一个不存在的目标名
- **THEN** 进程以非 `0` 退出码结束，并输出「未匹配到任何测试」类信息

### Requirement: 测试结果可诊断

测试模式 SHALL 在失败时输出失败的用例名、错误信息与堆栈；临时调试产物 MUST 统一写入 `tmp/` 目录，不得散落到源码或测试目录。

#### Scenario: 用例失败时的输出

- **WHEN** 某个用例断言失败
- **THEN** 输出中能定位到该用例名与失败原因

#### Scenario: 临时产物位置

- **WHEN** 测试过程产生了用于事后排查的中间产物
- **THEN** 这些产物位于 `tmp/` 目录下

### Requirement: 冒烟测试

构建产物 SHALL 附带至少一个冒烟测试，覆盖「启动 → 参数解析 → 日志落盘 → 事件循环可停止 → 协程可挂起与恢复」这条主链路，作为基础设施可用性的最低保证。

#### Scenario: 冒烟测试通过

- **WHEN** 以测试参数运行冒烟测试
- **THEN** 上述主链路各环节均通过，进程以退出码 `0` 结束
