# Proposal

## Why

牌表里 10 种即时锦囊现在只落地了 3 张（【无中生有】【南蛮入侵】【万箭齐发】）。这批做**最省的两张**：

- **【桃园结义】**把「目标 = 所有角色（含自己）」跑通，并第一次用上**回复**（`game:heal`）—— 之前的锦囊只有摸牌 / 伤害 / 打出三种效果。
- **【决斗】**把「交替响应」跑通：由目标先开始，两人轮流打出【杀】，先不出的挨 1 点 —— 与【杀】的单次响应、【南蛮】的一次响应都不同，它要**循环问同样两个人**。

两张都不牵扯「选**别人区域里**的牌」（过河拆桥 / 顺手牵羊）、「逼别人使用【杀】」（借刀杀人）、嵌套询问（无懈可击）⇒ **内核一行不改**。

**【五谷丰登】本批不做**（用户 2026-09-23 定：晚点做）。它要的口子比这两张多：① 牌定义需要「使用结算开始时 / 结束后」两个钩子 —— 官方「**指定目标后**亮出牌堆顶 X 张」不能写在 `'获取目标'` 里（`canUse` 每次算合法目标都会调用它），「剩余的牌进弃牌堆」又发生在整张牌结算完之后；② 询问要能「从**给定的一批牌**里选一张」（那批牌不属于任何人的牌区）。它另开一个变更。

## What Changes

- **内容侧两张牌**（`package/标准/卡牌/`）：
  - 【桃园结义】`'获取目标'` = 所有存活角色（含自己）；`'生效'` = `game:heal(ctx.target, 1)` —— 官方「◆对未受伤的角色无效」落到效果上（满体力者回复 0 点）。不声明 `limit`（锦囊不限次）。
  - 【决斗】`'获取目标'` = 一名其他存活角色；`'生效'` = 由**目标**先开始，`game:askCard(当前, '打出', { name = '杀' })`，谁没打出来谁受**另一方**造成的 1 点伤害。
- **用例：`server/test/rule/trick.lua` 扩充**（两张牌各若干条 + 并入既有的分类用例），不新增套件。
- **明确不做**：【五谷丰登】（见 Why）、过河拆桥 / 顺手牵羊（要"选别人区域里的牌"，牵扯**信息可见性** —— 别人手牌对谁可见）、借刀杀人（要"逼别人使用【杀】"）、无懈可击（要嵌套询问 `askSkill`）、延时锦囊与判定区、锦囊的前端表现。

## Capabilities

### New Capabilities

无（探索期不写规格：见 `openspec/config.yaml` 与 `AGENTS.md` 的「工作流」；本变更在 `.openspec.yaml` 里设 `skip_specs: true`，可执行契约由用例承担）。

### Modified Capabilities

无（同上）。

## Impact

- 内容：`package/标准/卡牌/{桃园结义,决斗}.lua`（新）；牌表不用动（两张牌本来就在里面）。
- 用例：`server/test/rule/trick.lua`（扩充）。
- 文档：`sanguosha-rules`（§4 牌分类表的已落地清单、§7 的「还没做」、§9.10 锦囊：两张牌的官方原文与已实现口径）、`moe-kill-dev` 的 `references/progress.md`（内容包现状与候选表）。
- **内核一行不改** —— 多目标、逐目标生效、询问与答复校验、伤害与回复都是现成的。
