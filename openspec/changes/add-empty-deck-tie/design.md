# Design

## Context

- **结局的形状**：`game:endGame { side, reason }`（`Game.Result`）—— `side` 用官方术语、`reason` 是给人看的中文短句；`endGame` **幂等**（只认第一次）、触发 `'游戏-结束'`、并把这一局的流程任务 `cancel` 掉；`game:getResult()` 有值就表示已经结束。
- **现有的判据**：`package/身份场/胜负.lua` 订阅 `'玩家-死亡'`，三种结局（主公方 / 反贼 / 内奸）；`package/身份场/奖惩.lua` 靠 `Depends` 排在它前面。
- **取顶的形状（刚落地）**：`OrderedZone:draw(n)` 从区顶取 n 张，不够就少给；**取空了会调一次 `setShortageHandler` 挂的回调**补牌，补不到就 `break`。`@基础/牌堆.lua` 挂的那个回调就是「把弃牌全部挪回抽牌 + `shuffle()`」。
- **内核不认识区名**：只有内容侧知道「抽牌堆 / 弃牌堆」这两个名字，也只有内容侧能判断「两堆都空」。
- **后果**：不足回调是**唯一**能同时看到「抽牌堆空了」和「弃牌堆也空」的地方。

## Goals / Non-Goals

**Goals:**

- 牌堆与弃牌堆都没有牌时，这一局以**平局**结束（发现即结束，不用等这一轮取牌走完）。
- 规则**只写一处**：摸牌 / 判定 / 将来任何取顶动作共用同一个判断。
- 结局取值与既有三种胜方并列，不新增字段、不新增方法。

**Non-Goals:**

- 不动 `身份场/胜负.lua`（平局与身份无关 ⇒ 属基础规则）。
- 不做「牌堆剩余不多」的预警、前端提示、或「平局时展示残局」这类表现。
- 不改 `endGame` / `Game.Result` 的形状（只补注释里的取值）。
- 不做「平局后不再取牌」的额外守卫（`endGame` 幂等 + 结束后内核本来就不起新结算）。

## Decisions

### D1 判据落在「不足回调」里（唯一知道两堆都空的地方）

```lua
-- package/@基础/牌堆.lua
deck:setShortageHandler(function (zone)     -- 抽牌堆空了：把弃牌全部洗回来
    if discard:count() == 0 then
        game:endGame { side = '平局', reason = '牌堆与弃牌堆都没有牌' }   -- 洗不回来 ⇒ 平局
        return
    end
    game:moveCard(discard:list(), zone)
    zone:shuffle()
end)
```

- 回调的语义本来就是「牌不够了，怎么办」——「弃牌也没得洗」正是这个问题的答案（`endGame`），不需要新概念。
- 一处覆盖：摸牌（`@基础/抽牌.lua`）、判定（`@基础/判定.lua`）、将来任何 `OrderedZone:draw` 的调用点。
- **备选（否）**：把「取不够 ⇒ 平局」写在每个调用点（`if #cards < need then endGame ... end`）—— 摸牌 / 判定各一份，将来每加一个取顶动作都要记住；规则散在多处，正是项目一直避免的写法。

### D2 结局取值用 `side = '平局'`

- `Game.Result` 已经是「给人看的 `side` + `reason`」⇒ 平局就是第四种 `side`，前端与装配侧不用学新形状（`getResult()` 有值 = 结束这条也照旧）。
- **备选（否）**：新增 `endGame(...)` 的 `draw = true` 字段，或把 `side` 改成可选 —— 会让「怎么判结束」分叉成两条（`side` 有没有值 / 有没有 `draw`），收益不抵成本。

### D3 发现即结束，不等这一轮取牌走完

- `deck:draw(n)` 一旦发现补不上，回调当场 `endGame`，`draw` 随即 `break`。
- **代价**：这一次取牌里**已经取到的牌**不会挪给谁（`game:moveCard` 是新结算，而内核在游戏已结束后不再起新结算 —— 既有口径，见架构第 12 节「多目标【杀】打死主公后不再打下一个目标」）。局已经结束，这几张牌的归属不影响任何后续行为。
- **备选（否）**：等这一轮取牌走完再结束（调用点各自判）—— 见 D1 的备选，规则要多处维护。

### D4 不动 `身份场/胜负.lua`

平局与身份无关（任何模式都该这么结），属基础规则 ⇒ 写在 `@基础`。两边都调 `game:endGame`，`endGame` 幂等 ⇒ 谁先发现谁结束，不会互相打架。

### D5 本批不做预警与表现

牌堆「快耗尽」的提示、平局时给前端播什么，都留给会话 / 协议批次（现在连前端都没有）。
