# Spec Delta

## MODIFIED Requirements

### Requirement: 牌的实例标识

牌 SHALL 以带有唯一标识的实例表示，使不同实例可以被区分与追踪；牌的定义内容（名称、花色、点数、效果）MUST NOT 由内核决定。该标识的唯一性 MUST 跨热重载保持：重载之后新建的实例 MUST NOT 复用重载前已经发出过的任何标识。

#### Scenario: 两个实例可区分

- **WHEN** 创建两个标签相同的牌实例
- **THEN** 它们具有不同的唯一标识，可被分别追踪

#### Scenario: 重载后标识不重复

- **WHEN** 创建若干牌实例，触发一次热重载，再创建新的牌实例
- **THEN** 新实例的标识与重载前已发出的任何标识都不同
