# Proposal

## Why

上一批把濒死改成「当场结算」时，**职责放错了地方**：

- **杀死玩家写在了规则里**：`@基础/濒死.lua` 的求桃循环跑完，看一眼 `体力 < 1` 就 `setAlive(false)`。按规则，**杀死玩家是濒死结算自己的结果**（濒死结算结束了、人还没脱离 ⇒ 死），不该由求桃这段循环顺手做。
- **「脱离濒死」的判据不对**：内核现在是「结算收尾时 `player:isAlive()` 为真就算离开了」。按规则，**体力一旦恢复为正就立刻移除濒死**（是个瞬间事件，不是收尾时的状态判断）；而且「还没杀过」不等于「已经脱离」。

## What Changes

- **内核：`Dying` 自己记「有没有脱离」，并负责杀人**
  - `Dying:leave()`：**脱离濒死**（幂等）—— 一被调就**当场**触发 `'濒死-离开'`（不再等结算收尾）。
  - `Dying:settle()`：触发 `'濒死-进入'` →（规则侧求桃）→ **还没脱离 ⇒ `player:setAlive(false)`**（触发 `'玩家-死亡'`）。内核仍然**不认识体力**：判定「是否脱离」只看规则侧有没有喊过 `leave()`。
- **内核：一个角色同时只有一个濒死状态**（用户 2026-09-23 定）
  - `game:enterDying(player, damage?)`：该玩家**正在濒死中** ⇒ **不新建、不重新结算**，只把它的 `damage` 换成这一次（**最后一次伤害 = 致死伤害**，用户原话：“濒死状态中继续受到伤害算最后一个伤害杀死玩家”）并**直接返回现有实例**；否则新建并当场结算。
  - 于是濒死期间继续被打到 ≤0 只是“这一下更狠”：求桃循环照旧继续（体力仍 ≤0），最终若是死，凶手按**最后一次伤害**算。
  - 已经脱离（喊过 `leave()`）的旧实例不算“正在濒死” ⇒ 这时再进濒死会新建。
- **内核：按玩家记「当前那次濒死」，给一个查询**
  - `game:getDying(player)` → `Dying?`（他正在濒死中就是那次结算，否则空）—— 结论：一个玩家一张账（1:1），不嵌套。
- **凶手改读那次濒死，内容侧的 `'凶手'` 标签退役**
  - `身份场/奖惩.lua` 在 `'玩家-死亡'` 里读 `game:getDying(死者).damage.from`（内核在结算收尾之后才清账）⇒ 「谁杀的」只有一个来源；换伤害时也不用再同步标签。
- **内容侧：`@基础/回复.lua` 统一管「体力回正 ⇒ 移除濒死」**（用户 2026-09-23 定）
  - 回血之后：`game:getDying(to)` 拿到那次濒死、且 `体力 > 0` ⇒ `dying:leave()`。任何回血来源（现在的【桃】、将来的回复技能）都自动生效。
- **内容侧：`@基础/濒死.lua` 只求桃，不再判死**
  - 保留「从濒死者开始按行动顺序绕一圈」的求桃循环（条件仍是 `体力 < 1`；有人把体力顶回正时由 `回复.lua` 喊 `leave()`，循环自然退出）；**删掉循环末尾的 `setAlive(false)`**。
  - `'濒死-离开'` 里清 `'凶手'` 标签，`'濒死-进入'` 里写标签 —— 不变。

## Impact

- 内核：`server/core/effect/dying.lua`（`leave()` / 结算收尾杀人 / 脱离标记）、`server/core/game.lua`（按玩家记账 + `getDying`）、`server/core/loader/env-meta.lua`（`'濒死-离开'` 仍是 `Dying` 上下文，类型不变，只改说明）。
- 内容：`package/@基础/回复.lua`（回正就离开）、`package/@基础/濒死.lua`（不再判死、不再写/清 `'凶手'` 标签）、`package/身份场/奖惩.lua`（改读 `game:getDying`）。
- 用例：`server/test/core/effect/dying.lua`（内核既是「进入 / 离开」的发起者，也是「杀死」的执行者；并覆盖「濒死中再受到伤害 ⇒ 返回同一个、致死伤害换成这一次」）、`server/test/rule/dying.lua`（求桃路径不变，补「脱离后不再算凶手 / 死亡由内核判」）、`server/test/rule/game-over.lua`（奖惩五条，凶手读法换掉）。
- 文档：`moe-kill-dev` 的 `references/architecture.md`（§12 的 `dying` / `enterDying` 行 + 新增 `getDying`）、`references/progress.md`；`sanguosha-rules` 的 §9.4（濒死实现段）。
